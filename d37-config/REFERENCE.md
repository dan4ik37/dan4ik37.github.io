# Настройки движка D37 — справочник

Сделано командой `d37 config dump --md` — руками не править. Формат файла: 1, поколение таблицы ключей (build): 1.

- **LOOK** — вид, темп, бюджеты: меняется сразу, даже посреди игры (страница перечитывает файл при возврате во вкладку и раз в 5 минут).
- **RULE** — правила игры (меняют результат симуляции): берутся при СТАРТЕ мира, пишутся в сохранение и в «привет» комнаты; у всех игроков общего мира и у сервера одни и те же. Новое значение дойдёт до мира при следующем запуске.
- ★ — самые полезные ключи группы.
- Число вне диапазона обрезается до края, неизвестный ключ пропускается — игра не падает, но `d37 config check` такой файл не пропустит.
