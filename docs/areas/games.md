## Игры (#/games, games.sql)
- Витрина и общее API — `js/features/games.js` (`GAMES`, `gamesApi(id).report(key, win, score, localBest)`).
  Сами игры — `js/games/*.js`, грузятся лениво при открытии; регистрируются в `GAME_IMPL[id] = { mount, unmount }`.
  Новая игра = запись в `GAMES` + файл + ключ в `game_score_cap`/`game_win_xp` (games.sql) + подпись в `gameBestLabel`.
- «Города»: словарь `js/games/cities-data.js` (города России — пакет russia-cities-data, ISC, уведомление в файле;
  мир — свой список). Пересобрать: скрипт из сессии не сохранён — формат строки `название|страна|население|шир|долг`.
- Сервер: `game_result()` (ключ игры из белого списка, очки ≤ потолка, не чаще раза в 5 с, XP за победу — до 15 в день,
  source `game`), `game_top()`. Ачивки игр — в `my_achievements` (progression.sql) по `game_stats`.
- «Города» онлайн: `#/games/cities/<код>` — Supabase Realtime (канал `cities-duel-<код>`, broadcast + presence,
  без таблиц). Хозяин — кто раньше в комнате, шлёт start; ходы проверяет каждая сторона. Победа короче 3 своих
  городов не отправляется (защита от накрутки двумя вкладками). Проверять — двумя вкладками на localhost.
- Онлайн для остальных игр — общий модуль `js/games/room.js` (`GameRoom.join/lobby/newCode`), сейчас: шашки,
  крестики-нолики, морской бой (`sea.js`: каждый хранит свой флот, отвечает на выстрел `res` hit/miss/sunk;
  бот проверяется в node через `GAME_IMPL.sea._test`). Служебное поле отправителя в сообщениях — `_by` (не `from`: у ходов шашек from — клетка).
  Шашки: правила проверены на позициях в node через `GAME_IMPL.checkers._test`.
- «⚔️ Соревнование» для одиночных игр (Угадай видео, 2048, Лови донаты, Реакция, Змейка, Найди пару) — `js/games/versus.js`:
  хозяин шлёт seed, у обоих одинаковый генератор (`Versus.rng`), счёт соперника вживую, результат — `<игра>_duel`
  (только если оба доиграли). Игра даёт `run(stage, rng, hooks)` и зовёт `hooks.progress/done`; случайность — только
  через rng, позиции/скорости — в долях поля. Если в комнату пришёл другой человек (или соперник обновил страницу),
  хозяин начинает новую партию — это же правило в шашках, крестиках-ноликах и «Городах».
- Рекорды: «За неделю» (`game_top_week`, по game_log) / «За всё время» (`game_top`); «Чемпионы дуэлей» (`duel_top`) —
  победы в `%_duel` и `%_online` во всех играх.
- Задание дня: `daily_quest_code()` (12 заданий по кругу от даты по МСК), прогресс — по `game_log` (пишет game_result,
  хранится 14 дней), награда 50 XP — `claim_daily_quest()` (source `daily`, ref = дата). Тексты — `DAILY_QUESTS` в games.js.
- Задания недели и бесплатный сезонный путь (T-015, 22.10.2026; games-more.sql — конец файла; docs/ECONOMY.md §10): 6 заданий недели
  (пн 00:00 МСК; weekly_quest_codes — место s недели w: вариант (w + s) mod k, без случайности), прогресс — сервер (weekly_quest_stats:
  game_log, xp_ledger 'daily'/'watch', user_visits — по индексам), claim_weekly_quest → XP и 🪙 'weekly' + ⭐. Сезон = месяц МСК
  (quest_rule s_months; № 1 — ноябрь 2026, октябрь — пробный № 0); ⭐ — триггеры trg_season_on_game_win (первые 10 побед в день) и
  trg_season_on_daily_quest + задания недели; season_claim — награды лестницы (🪙, вещь темы → coin_wallet.items, рамка и титулы →
  season_owned), за прошлые сезоны тоже; титул — season_title_set (user_titles 'ss:ГГГГ-ММ:1|2'; achTitleDef в achievements.js — для
  ников и профиля), рамка — season_frame_set / season_frames (xp.js applyLevelFrame, .lv-frame-ss[data-ss]). Витрина — quest_hub()
  (renderQuests в «Играх», renderProfileQuests на своём профиле; подсказка после партий — questAfterGame, не чаще раза в 45 с). Платного
  пути нет (season_paid_on → false). Числа: quest_rule ↔ QUEST_NUM, season_ladder ↔ SEASON_LADDER, season_themes ↔ SEASON_THEMES,
  weekly_quest_pool ↔ WEEKLY_QUESTS (порядок важен) — economy-test раздел 7; проверка с датой — *_at (только сервер).
- «Поддержать стрим / Позвать друга» — плашка `gamesSupport()` в games.js после победы или рекорда (не чаще раза
  в 10 мин, максимум 3 за визит); ссылка «позвать» ведёт на SEO-страницу `/games/<id>`.
- «📣 Вызов» (кнопка в шапке игры, `gamesChallenge()`) — ссылка `/games/<id>?s=<рекорд>&n=<ник>`: api/game.js
  показывает «Ник набрал N — побьёшь?» в заголовке/превью (canonical — чистый /games/<id>). Подписи результата на
  сервере — `scoreLabel()` в games-seo.js (как `gameBestLabel` в games.js). Картинки превью — `img/games/<id>.png`,
  рисует `img/games/_make-cards.py` (Pillow + шрифты Windows; новая игра → добавить строку и перезапустить).
- «5 букв» (`js/games/words.js`): слово дня (одно на всех, день №1 = 03.10.2026, смена в полночь МСК), свободная
  игра, соревнование. Словари — `js/games/words-data.js`, собирает `scripts/make-words.py` из npm `dictionary-ru`
  (BSD-3, уведомление в файле данных). Загадываемые слова — свой список в скрипте. Ключи сервера: words / words_free / words_duel.
  Логика подсветки — `GAME_IMPL.words._test.evaluate` (проверять в node, повторы букв!).
  «💡 Подсказка» — одна буква на слово только для VIP/персонала (`hasPerks`), остальным — как получить VIP (донат / 30 ур.);
  в «Поделиться» помечается 💡. Подсказка дня сохраняется в d37_words_day сразу (иначе перезагрузкой берут вторую).
- «Сегодня на сайте» на главной (блок `#today`, `renderToday()` в games.js): слово дня, игры, архив видео. Пункт «🎮 Игры»
  в нижнем меню телефона с красной точкой, пока слово дня не сыграно (`gamesDailyDot()`, по localStorage d37_words_day).
- Охота за секретами: `js/features/secrets.js` (+ `secrets.sql`). 7 знаков ✦ (`data-secret="код"`): avatar (5 кликов по
  аватарке, easter-egg.js), footer, games (под рекордами), archive (последняя страница /videos), horror (/topic/horror),
  levels («Что даёт уровень»), words (итог слова дня). Находки — localStorage, при входе уходят в secret_found().
  Все 7 → радужный ник на 30 дней (`.nick-rainbow`, в чате `.cu-nick`, в профиле #profileNick) + 100 XP. Панель — #secretHunt в «Играх».
- «Задонатил — не засчиталось?»: `js/features/donation-claims.js` + claim_donation (с 22.10 — в premium.sql). Форма — в блоке
  «Логин для доната» своего профиля. Само привязывается, только если: один такой донат, меньше donor_rule('auto_max') (300 ₽), имя
  ≤ 2 опечатки от ЛОГИНА для доната (ник — только подсказка админу), донат после регистрации и после того, как логин стал твоим
  (reserved_donate_logins.reserved_at); анонимные — никогда. Иначе — заявка админу с причинами (flags). Админ — «💸 Донаты: проверка»
  (donor_admin_state: заявки с доказательствами и текстом доната, «ждут решения», подозрительные старые привязки — «в порядке» /
  «не считать в статус», занятые системой ники), привязать по номеру доната — donor_admin_assign. Один донат — один аккаунт.
- Профиль: настройки аккаунта — внизу; «О себе» на чужом профиле без текста скрыт; ачивки — полученные + 8 закрытых,
  остальные по кнопке; карточка «🎮 Игры на сайте» (`renderProfileGameStats` в games.js, по game_stats).
- Пока открыта игра, горячие клавиши страниц (`hotkeys.js`) отключены — стрелки/цифры принадлежат игре.

## «Орда» (#/games/horde, js/games/horde.js) — выживание в духе Vampire Survivors
- Симуляция (step, шаг 1/60 с) отдельно от рисования; проверка в node: `GAME_IMPL.horde._test` + бот (скрипт в сессии: бот
  уворачивается и собирает кристаллы; цель баланса — средний бот живёт 5–6 мин, иногда побеждает). Ничего не меняй в цифрах, не
  прогнав бота.
- Игрок = свой персонаж (в руке оружие героя), питомец бежит следом, след за спиной. 6 героев (цены — coin_price hero:*; «Денчик» —
  бесплатно для VIP), 11 оружий с эволюциями (оружие 5 ур. + своя пассивка), 11 пассивок, боссы 5:00 Дракон и 9:00 Жнец, 10:00 — победа.
- Монеты забега → `D37Coins.run('horde', …)` (до 300); возрождение раз за забег — реклама или 30 монет; «×2 за рекламу» на итогах.
  VIP: 4 варианта на уровне, ×2 монеты. Магазин улучшений (up:*) действует в одиночной игре, не в соревновании.
- SEO-страница `/games/horde` (games-seo.js, «игра как Vampire Survivors онлайн»), картинка `img/games/horde.png`.
- Кооп `#/games/horde/coop/<код>` (комната GameRoom 'horde-coop'): хозяин считает мир, напарник (`G.viewOnly`) рисует по снимкам и
  сам двигает своего героя. Снимки — двоичные (`encodeSnap/decodeSnap`, ~0,5 КБ, 15/с напрямую, 5/с через Supabase), сводка 'st' 4/с,
  эффекты 'fx'. Уровень общий (выбирают оба, ждём ≤25 с), упавшего поднимает напарник (2,5 с рядом) или встаёт сам (реклама/монеты).
  Ключ сервера horde_coop. Проверено двумя вкладками: связь напрямую, выбор улучшений, снимки.
- Сеть для игр в реальном времени — `js/games/netplay.js` (`NetPlay.start(room, …)`): WebRTC DataChannel напрямую (STUN Google и
  Cloudflare), Supabase — только знакомство; не соединилось за 7 с → «relay» через комнату Supabase (5 быстрых сообщений в секунду).
  Брать для любых новых игр вдвоём в реальном времени (лимит сообщений Supabase бесплатного тарифа — 2 млн в месяц).

## «Башни» (#/games/td, js/games/td.js) — Tower Defense
- Симуляция детерминированная (шаг 1/30 с, без Math.random и без `**`/sin/cos — только + − × ÷ sqrt), состояние — простой JSON.
  Проверка в node: `GAME_IMPL.td._test` + бот-строитель (скрипт в сессии): разные башни → проходит 20 волн за ~15 мин, «только
  лучники и пушки» → гибнет на 11-й (броня 🐢/🐲/🐉 — пробивают только ⚡ и 🎯; при первой броне — подсказка).
- 3 карты (MAPS: точки дороги, последняя — замок), 5 башен × 3 уровня, 8 врагов, волны — `waveList(n)`, ×1/×2/×3.
- «⚔️ Битва» — versus.js + свои сообщения (`hooks.send` → `opts.onMsg`): отправка монстров сопернику (SENDS).
- «🤝 Вместе» (`#/games/td/coop/<код>`) — lockstep: оба считают один и тот же мир; по сети только команды с номером шага
  (через LAG=10 шагов) и отметки «я на шаге N»; шаг можно делать, пока он < чужой отметки + LAG. Раз в 90 шагов — сверка
  контрольных сумм, разошлись → хозяин шлёт весь мир ('sync'). Проверено двумя вкладками: 0 пересинхронизаций.
  `GAME_IMPL.td._dbg()` — шаг, сумма, число пересинхронизаций.
- Реклама за награду (раз за игру): «+100 золота» и «Продолжить: +10 жизней» (или 30 монет). Монеты: 4 за волну + 50 за победу.

## Карты и настолки на 2–4 игроков: стол (js/games/table.js)
- `TableRoom.join(game, code, { max, onSeats, onMessage, onPrivate })`: места по времени входа, первый — хозяин стола (раздаёт и
  проверяет ходы, ведёт ботов на пустых местах). Ключи ECDH в presence; `room.sendTo(id, msg)` — AES-GCM для одного игрока.
  В картах ВСЁ идёт через sendTo (и состояние стола, и ходы): шифр подтверждает отправителя — ход за другого и «состояние от
  хозяина» не подделать, чужую руку не подсмотреть. Сообщений мало (ход — 1–3), поэтому всё через Supabase, без WebRTC.
- «Одна!» (#/games/uno, js/games/uno.js) — карты по правилам Уно (название своё: UNO — товарный знак; на SEO-странице — «как
  Уно»). Движок — чистые функции (`_test`): 2000 партий ботов без ошибок, 108 карт всегда на месте. Человек онлайн думает
  > 30 с — ход за него; ушёл — за него доигрывает бот. Ключи сервера: uno (с ботами), uno_online.
- «Дурак» (#/games/durak, js/games/durak.js) — подкидной, 36 карт, 2–4 игрока, тот же стол. Движок — чистые функции (`_test`):
  3000 партий ботов — 0 ошибок и зависаний. Нечего подкинуть — «бито» само. Онлайн человек думает > 25 с — «беру»/«пас»/младшая.
  Ключи: durak, durak_online (очки — 1 за «не дурак», рекорды — по победам). Значок — ♠️ (🂡 нет в шрифтах Windows).
- «Бильярд» (#/games/pool, js/games/pool.js) — пул «восьмёрка»: бот 3 уровней (перебирает удары и просчитывает физикой),
  вдвоём на экране, онлайн (room.js, 2 игрока). Физика детерминированная (шаг 1/240 с, только + − × ÷ sqrt): по сети — только
  удар {dx, dy, p} (округлённый roundShot) и место битка; исход каждый браузер считает сам. Проверка в node (`_test`):
  бот против бота, детерминизм, шары не «зависают» в створе лузы. На телефоне стол вертикальный (`rot`).
  Ключи: pool_easy / pool_normal / pool_hard / pool_online.
- «Лудо» (#/games/ludo, js/games/ludo.js) — как Ludo King, 2–4 игрока, стол table.js; кубик бросает хозяин стола. Поле 15×15:
  TRACK (52 клетки), START, SAFE (★), HOME (финишные дорожки). 2000 партий ботов — 0 ошибок. Ключи: ludo, ludo_online.
- «Нарды» (#/games/nardy, js/games/nardy.js) — длинные: голова (1 шашка за ход, первый ход 6-6/4-4/3-3 — 2), запрет
  «заборчика» из 6, обязательный максимум кубиков и «больший кубик» (`maxRem` с запоминанием — иначе дубли считаются
  слишком долго), марс. Позиции у каждого свои (0 — голова), на доске abs = pos (белые) / pos+12 (чёрные). Бот — все
  итоговые позиции хода + оценка. Онлайн — стол table.js на 2, кубики бросает хозяин. Ключи: nardy_easy / nardy_hard / nardy_online.
- «Арена» (#/games/arena, js/games/arena.js) — перестрелка 1 на 1 в реальном времени: два «джойстика» пальцами, кусты,
  аптечки, «супер»; до 5 побед или 2,5 мин. Бот (3 уровня, упреждение, объезд стен) — бот против бота в node, все партии
  кончаются. Онлайн — netplay.js: хозяин считает пули/урон и не шлёт гостю соперника из кустов; свой бег каждый считает сам.
  Ключи: arena_easy / arena_normal / arena_hard / arena_online.
- «Шахматы» (#/games/chess, js/games/chess.js) — все правила; генерация ходов проверена perft на 4 эталонных позициях
  (начальная, Kiwipete, №3, №4 — числа сошлись). Компьютер: постепенное углубление + альфа-бета + лимит позиций по уровню
  (Мастер — глубина 4, до ~0,6 с), штраф за повтор позиции. Фигуры — свои SVG (PATHS): символ ♟ в Windows — цветной эмодзи.
  Онлайн — стол table.js на 2 (хозяин белыми и проверяет ходы). Ключи: chess_easy / chess_normal / chess_hard / chess_online.
- «Блоки» (#/games/blocks, js/games/blocks.js) — как Block Blast: поле 8×8, 3 фигуры (DEFS, 37 штук с весами), canvas.
  Перетаскивание (палец — фигура поднята над пальцем) или «нажми фигуру → нажми клетку». Очки: клетка +1, линии 40·L·(L+1),
  × комбо (линии хотя бы раз за 3 хода, множитель до ×5), чистое поле +300. Одиночная партия — localStorage d37_blocks_save.
  Не помещается → раз за игру новые фигуры за рекламу / 30 монет (rescue). Монеты: счёт/50, до 150 (RUN_CAP и coin_run_cap).
  Соревнование — versus.js, без «подсказки» в раздаче (иначе фигуры у соперников разойдутся). Победа (XP) — от 2000 очков.
  Движок — GAME_IMPL.blocks._test; бот с планом на 3 фигуры живёт 600+ ходов, жадный — ~35 (сложность нормальная).
  Ключи: blocks / blocks_duel. Превью — своя картинка в _make-cards.py ('draw:blocks').
- Пасьянсы «Косынка» (#/games/kosynka, по 1/3 карты) и «Паук» (#/games/pauk, 1/2/4 масти) — один файл js/games/solitaire.js
  (GAME_IMPL.kosynka и .pauk, движок — ._test). Карты — DOM (.scd, позиции transform, CSS-переход), стол — .sl-board
  (isolation: карты не вылезают поверх шапки). Нажатие = лучший ход (bestTarget: дом → ряд), перетаскивание — к ближайшей
  подходящей стопке. Отмена — снимки JSON (hist), автосбор косынки (canAuto/autoMove). Сохранение — d37_sol_<игра>.
  Очки косынки как в Windows + бонус 700000/сек за победу; паук: 500 − ходы + 100 за масть. Соревнование — только косынка по 1.
  Ключи: kosynka / kosynka3 / kosynka_duel, pauk1 / pauk2 / pauk4. Монеты за победу: косынка 25/40, паук 30/60/100.
  Бот (node) раскладывает косынку по 1 в ~30%; паука перебор решает редко — люди играют лучше, правила проверены тестами.
  Классы стола: sl-kos / sl-spd / sl-fc (не sl-s — это подпись в окне итога, у неё max-width).
- «Свободная ячейка» (#/games/freecell) — там же, kind 'f': раздачи №1–32000 генератором Windows (msDeal; №1 сверена с
  эталоном), ячейки c0..c3, перенос (ячейки+1)×2^(пустые ряды) (maxMove), «безопасные» карты сами уходят в дом (autoFound).
