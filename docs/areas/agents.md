## Как работаем с агентами (владелец 22.10: «чтобы знать, что сделали, что нужно, что доработать и чего не хватает»)
- Доска — docs/TASKS.md: номер T-NNN, статус (🟢 в работе / ✅ готово / ⏳ очередь / 🙋 ждёт владельца / ⛔ не делаем), кто, ветка.
  Правит только главный (координатор) — после запуска и после слияния; агенты доску не трогают (конфликты).
- Карточек по-русски от агентов НЕТ (владелец 22.10: «зачем по-русски — главное, чтобы ты докладывал; пусть не тратят лимит
  просто так»). Агент в конце шлёт главному КОРОТКИЙ отчёт по-английски: Done / Not done / Gaps noticed / Tests (числа) / Owner
  actions (SQL + проверки REST) / Branch. Главный по нему обновляет доску и докладывает владельцу по-русски, коротко.
- Задание агенту (по-английски, сжато): номер задачи, слова владельца, разделы CLAUDE.md и документы, критерии готовности,
  какие файлы его и какие НЕ трогать (кто ещё работает), правила (SQL — только в файл области; temp — E:\claude-tmp\<задача>\;
  коммиты по шагам; ключи и пароли не вводить). Экономия лимита: тесты — только нужные на шаге (все — один раз в конце), без
  лишних документов и снимков, заметки в CLAUDE.md — коротко (факты для следующих агентов), документы для агентов — по-английски.
- Приёмка (главный): диф и карточка → тесты заново → слияние (GAMES_VER выше обеих) → выкладка → проверка файлов на сайте →
  доска (✅, хвосты из «Не сделано» и «Чего не хватает» — новыми T-NNN в очередь) → владельцу коротко: что изменилось, что ему сделать.
- Одновременно 4–6 агентов (лимит 5 часов и недели общий с Backrooms — перед запуском get_usage); задачи, трогающие одни файлы,
  — по очереди (колонка «после чего» на доске).
- Качество (владелец 22.10: «мне нужен оптимизированный код, а не на отвали — чтобы не вылетало и не лагало!»): у каждой правки —
  замер до/после на профиле телефона (ЦП ×4 медленнее, «средняя»), без мусора за кадр в горячих циклах (пулы, типизированные
  массивы), без утечек (20 открытий/закрытий), без ошибок в 10–15-минутном прогоне, запасной путь при сбое (игра/страница живёт);
  SQL на горячих путях — по индексам. Числа — в отчёте агента; без чисел работа не принимается. Чужие «альфа»-основы (ArtCraft) —
  только если пройдут те же замеры, иначе — лёгкая стабильная основа.
- Не изобретать с нуля (владелец 22.10: «за основу фоторедактор и другое можно взять с бесплатной работы, чтобы не придумывать
  с нуля»): для больших инструментов сначала искать готовый открытый проект с разрешающей лицензией (MIT, Apache-2.0, BSD, ISC;
  НЕ GPL/AGPL и НЕ «только некоммерческое» — сайт с рекламой), брать за основу и дорабатывать: лицензия и уведомление в файле,
  подключение с jsDelivr с точной версией (как Rapier, clang, Phaser); положить чужой код в репозиторий — только с разрешения
  владельца на скачивание. Модели ИИ — тоже только с разрешающей лицензией.
