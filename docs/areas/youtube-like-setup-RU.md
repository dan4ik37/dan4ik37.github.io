# Настоящий лайк на YouTube с сайта — что сделать тебе (26.11.2026)

Ты сказал «Yes, prepare it». Код готов и **выключен** (`YT_LIKE_REAL = 'off'` в `js/core/config.js`): для зрителей ничего не
поменялось — «👍 Лайк на YouTube» по-прежнему открывает ролик на YouTube. Включается по шагам ниже. Аккаунты, кабинеты, секреты —
только ты; я ничего в Google не нажимаю.

**Как будет работать.** Человек нажимает «👍 Лайк на YouTube» (кнопка та же и там же: окно ролика, Shorts, карточки) → гость сначала
входит обычным «Продолжить с Google» (он по-прежнему просит у Google только имя и почту — никакого YouTube) → один раз Google
спрашивает: «Разрешить сайту управлять оценками на YouTube?» → человек возвращается на ту же страницу, в тот же Short, на ту же
секунду ролика → лайк стоит на YouTube **без второго нажатия**, 👍 залита, строка «👍 Лайк поставлен на YouTube». Нажал ещё раз — лайк
снят. Наград за лайки нет и не будет (правила YouTube). Не вышло (отказ, лимит, встроенный браузер) — кнопка снова просто ссылка на
YouTube и одна строка «почему».

**Пропуск Google живёт только в этой вкладке браузера, не дольше часа** — ни на сервер сайта, ни в базу он не попадает.

## Шаг 1. Включить «YouTube Data API v3» (2 минуты)

1. https://console.cloud.google.com → вверху выбери проект **`dan4ik37-site`** (тот, где делал вход через Google).
2. ☰ → **«API и сервисы»** → **«Библиотека»** (Library).
3. В поиске: `YouTube Data API v3` → открой → **«Включить»** (Enable). Если там уже «Управление» (Manage) — уже включено, дальше.

## Шаг 2. Адрес возврата в клиенте (1 минута)

1. ☰ → **«API и сервисы»** → **«Учётные данные»** (Credentials) → клиент **`dan4ik37 сайт`** (Веб-приложение).
2. **«Разрешённые источники JavaScript»** — там уже `https://dan4ik37.vercel.app` (ничего не меняй).
3. **«Разрешённые URI перенаправления»** → «Добавить URI» → вставь **ровно** (со слешем в конце):
   `https://dan4ik37.vercel.app/`
   Старый адрес `https://zdisuowyjgqirhvcyjfq.supabase.co/auth/v1/callback` **не удаляй** — он нужен для входа.
4. **«Сохранить»**. Вверху этой же страницы — **«ID клиента»** (длинный, кончается на `.apps.googleusercontent.com`). Это **не секрет** —
   пришли его мне. **«Секрет клиента» не присылай никому** — он нужен только Supabase, и он там уже есть.

## Шаг 3. Право YouTube в «Доступ к данным» (2 минуты)

1. ☰ → **«API и сервисы»** → **«Окно запроса доступа OAuth»** → слева **«Доступ к данным»** (Data access).
2. **«Добавить или удалить области»** (Add or remove scopes) → в фильтре: `youtube.force-ssl` → поставь галочку у
   `https://www.googleapis.com/auth/youtube.force-ssl` («See, edit, and permanently delete your YouTube videos, ratings, comments and
   captions») → **«Обновить»** (Update) → **«Сохранить»** (Save).
3. Оно попадёт в **«Конфиденциальные области»** (sensitive scopes) — так и должно быть.

Почему именно это право: лайк (`videos.rate`) Google разрешает только с одним из трёх прав — `youtube.force-ssl`, `youtube`,
`youtubepartner`. Более узкого нет; `youtubepartner` — для владельцев контента, `youtube` — то же «управление» без обязательного
шифрования. Берём `youtube.force-ssl`.

## Шаг 4. Кто сможет пробовать, пока Google не проверил

- На сайте я включу режим **`'test'`**: настоящий лайк — только у **админов сайта** (у тебя) и у аккаунтов, чьи номера впишем в
  `YT_LIKE_TEST_IDS`. Остальным — по-прежнему ссылка.
- **«Аудитория» → «Тестовые пользователи»** в Google Cloud: этот список работает, **только если приложение в состоянии «Тестирование»**.
  У тебя оно, по инструкции входа, **опубликовано** («В рабочем режиме») — тогда список ничего не меняет, вписывать никого не нужно.
  **Не переводи приложение обратно в «Тестирование»** — тогда обычный вход через Google перестанет работать у всех, кроме списка.
  (Если всё-таки в «Тестировании» — впиши туда свою почту Google: «Аудитория» → «Тестовые пользователи» → «Add users».)
- Пока Google не проверил приложение, у того, кто нажимает 👍 первый раз, Google покажет экран **«Google не проверил это приложение»**
  (Google hasn't verified this app). Пройти: **«Дополнительные настройки»** (Advanced) → **«Перейти на сайт dan4ik37.vercel.app
  (небезопасно)»**. И ещё ограничение Google: **не больше 100 новых людей** увидят этот экран и дадут разрешение, пока нет проверки.
  Поэтому до проверки — только `'test'`. Обычного входа (имя и почта) это **не касается** — его Google не проверяет.
  *(Как выглядит экран и где кнопка — по описанию Google; вживую я его не видел.)*

## Шаг 5. Проверка приложения в Google (подаёшь ты; обычно от нескольких дней до нескольких недель)

☰ → **«API и сервисы»** → **«Окно запроса доступа OAuth»** → **«Центр проверки»** (Verification Center) → «Подготовить к проверке»
(Prepare for verification). Google спросит:

1. **Главная страница и политика конфиденциальности** — `https://dan4ik37.vercel.app` и `https://dan4ik37.vercel.app/privacy`
   (та же ссылка, что во «Брендинге»). В политике должен быть раздел про YouTube — **черновик ниже, нужно твоё «да»**.
2. **Подтверждённый домен.** Google требует, чтобы домен главной страницы был **твой** и подтверждён в Search Console
   (https://search.google.com/search-console → свойство `https://dan4ik37.vercel.app` → «Подтверждено»). ⚠ Риск: адрес
   `*.vercel.app` принадлежит Vercel, и проверяющий может потребовать **свой домен** (ты его и так планируешь — для AdSense). Я этого
   не проверял; если откажут из-за домена — сначала свой домен, потом подача заново.
3. **Зачем право (scope justification)** — вставь в поле для `youtube.force-ssl` (по-английски, проверяющие читают английский):

   > dan4ik37.vercel.app is the website of the YouTube channel @Dan4ik37Yt. Each video, Short and video card on the site has a
   > button labelled "👍 Like on YouTube". When a viewer taps it, we call `videos.rate` (rating=like, or rating=none when they tap
   > again to remove it) for that one video, and `videos.getRating` to show whether their YouTube account already likes it. The
   > permission is requested only at that moment, never at sign-in. `videos.rate` and `videos.getRating` accept only the scopes
   > youtube, youtube.force-ssl or youtubepartner; youtube.force-ssl is the narrowest of them (youtube.readonly cannot rate).
   > The access token stays in the viewer's browser tab (sessionStorage, at most one hour); it is never sent to our servers or
   > stored in our database. We do not read, store or share any other YouTube data, and there are no rewards for likes.

   (По-русски: сайт канала; у каждого ролика кнопка «Лайк на YouTube»; по нажатию ставим или снимаем лайк этому одному ролику и
   смотрим, лайкнул ли уже; право спрашиваем только тогда, не при входе; это самое узкое право, которым можно ставить лайк; пропуск
   живёт только во вкладке, у нас не хранится; наград за лайки нет.)
4. **Видео-демонстрация** — загрузи на YouTube как **«Доступ по ссылке»** (Unlisted), ссылку — в форму. **Язык Google — английский**
   (на экране выбора аккаунта внизу → English), иначе вернут. Сценарий (2–3 минуты, запись экрана телефона или компьютера):
   1. Открыть `https://dan4ik37.vercel.app` — видна главная, адрес в строке браузера.
   2. Показать ссылку **Privacy** внизу страницы → открыть → прокрутить до раздела про YouTube API Services.
   3. Назад → войти через **«Продолжить с Google»** — показать, что экран входа просит только имя и почту.
   4. Открыть любой ролик (или Shorts) → нажать **«👍 Лайк на YouTube»**.
   5. Экран Google: видно название приложения, **ID клиента в адресной строке** (кликнуть по адресу и медленно провести — проверяющие
      сверяют ID) и право **«See, edit, and permanently delete your YouTube videos, ratings, comments and captions»** → «Continue» /
      «Allow».
   6. Возврат на тот же ролик → кнопка стала залитой, строка «👍 Лайк поставлен на YouTube».
   7. Открыть этот ролик на youtube.com в другой вкладке → показать, что лайк стоит.
   8. На сайте нажать 👍 ещё раз → лайк снят → обновить youtube.com → лайка нет.
   9. Показать, как отозвать доступ: `https://myaccount.google.com/permissions` → dan4ik37 → «Удалить доступ».
5. **Контакты, логотип** — как во «Брендинге». Ответы Google приходят на почту; если просят исправить — пришли мне текст письма.

## Шаг 6. Лимит YouTube (квота)

- Бесплатно: **10 000 единиц в сутки на весь проект**. Один лайк (`videos.rate`) = 50 ед., проверка «лайкнул ли» (`getRating`) = 1 ед.
  на пачку до 50 роликов → **около 200 лайков в сутки на весь сайт**. Сутки — по времени Калифорнии (полночь там = 11:00 в Астане).
- ⚠ Если ключ, которым сайт читает цифры роликов (`YT_KEY`, сервер `/api/vstats` и лента), сделан **в этом же проекте** — он тратит
  те же 10 000. Проверить: «API и сервисы» → «Учётные данные» → есть ли там «Ключ API» с тем же началом `AIzaSyA0dK…`.
- Кончилась квота — у человека кнопка до полуночи по Калифорнии снова ссылка на YouTube со строкой «Лайки с сайта на сегодня
  закончились», без потока ошибок.
- Поднять квоту: форма **«YouTube API Services – Audit and Quota Extension Form»** — https://support.google.com/youtube/contact/yt_api_form
  Google проверяет сайт на соблюдение правил YouTube API (политика конфиденциальности, никаких наград за лайки, подписи «на YouTube»,
  удаление данных), занимает недели. Подавать, когда лайков станет больше ~150 в день: «API и сервисы» → «YouTube Data API v3» →
  «Квоты» показывает расход.

> ### Лайки на YouTube (YouTube API Services)
> Кнопка «👍 Лайк на YouTube» на сайте использует **YouTube API Services**. Нажимая её и давая разрешение Google, ты соглашаешься с
> [Условиями использования YouTube](https://www.youtube.com/t/terms); твои данные в Google обрабатываются по
> [Политике конфиденциальности Google](https://policies.google.com/privacy).
>
> **Что сайт делает с разрешением.** Только ставит или снимает лайк тому ролику, где ты нажал кнопку (`videos.rate`), и проверяет,
> стоит ли уже твой лайк на роликах, которые ты видишь на сайте (`videos.getRating`), — чтобы показать залитую 👍. Больше ничего из
> твоего аккаунта YouTube сайт не читает и не меняет. Лайк ставится только по твоему нажатию. Наград за лайки нет.
>
> **Где хранится.** Пропуск доступа от Google хранится только в этой вкладке твоего браузера (sessionStorage) и действует не дольше
> часа; он не отправляется на сервер сайта, не записывается в базу данных и никому не передаётся. Закрыл вкладку — пропуск исчез.
> Сайт не хранит твои лайки YouTube у себя.
>
> **Как отозвать доступ.** В любой момент: [myaccount.google.com/permissions](https://myaccount.google.com/permissions) → dan4ik37 →
> «Удалить доступ». После этого сайт не сможет ставить лайки от твоего имени, пока ты снова не разрешишь.
>
> **Дети.** Детям до 13 лет кнопка лайка на YouTube на сайте работает как обычная ссылка на YouTube.
