# Вход через Google и другие сервисы — что сделать тебе (по порядку)

Владелец 25.11.2026: «вход через гугл и другие платформы, чтобы люди могли ставить нормально лайк и смотреть видео и стримы».

**Что уже готово на сайте (выложено, флаг `AUTH_SOCIAL` в `js/core/config.js`):**
- одно окно входа на весь сайт: сверху большая белая кнопка **«Продолжить с Google»**, ниже — другие включённые сервисы,
  почта — последней;
- гость нажал ❤ (у ролика, у стрима, у игры) или «Следить» → окно входа → после входа он **на той же странице, на том же
  месте, ролик с той же секунды**, и ❤ уже стоит — нажимать второй раз не надо;
- новый аккаунт через сервис: одно маленькое окошко — **ник** (подсказан из имени в Google, только имя, без фамилии) и
  **год рождения** (дети и взрослые общаются раздельно, как и раньше; «не хочу указывать» — правила «возраст не указан»);
- аккаунт по почте Gmail + «Продолжить с Google» с той же почтой = **один аккаунт** (не два);
- во встроенных браузерах (Telegram, VK, Instagram, TikTok…) Google не пускает — вместо его кнопки подсказка
  **«Открыть в браузере»**;
- пока сервис не включён — его кнопки **нет совсем** (сломанной кнопки не будет).

**Сейчас (проверено с сервера 25.11):** Google, Discord, Twitch, GitHub — выключены; VK, Яндекс, Telegram — выключены;
`auth-links.sql` — выполнен ✅; часть 20 (❤ на сайте) — **не выполнена** (пока её нет, кнопки ❤ у роликов и стрима не видно;
❤ у игр работает и так).

Ничего из этого я сам не делаю: аккаунты, ключи, секреты, кабинеты — только ты. Секреты никому не присылай (и мне тоже):
они вставляются только в Supabase или Vercel. Номер «Client ID» — не секрет.

---

## Шаг 1. Google (главное — 10 минут)

**1.1. Google Cloud — получить «ID клиента» и «Секрет»**
1. Открой https://console.cloud.google.com → вверху «Выбрать проект» → **«Создать проект»** → название `dan4ik37-site` → «Создать».
2. Слева ☰ → **«API и сервисы»** → **«Окно запроса доступа OAuth»** (OAuth consent screen) → «Начать» / «Get started»:
   - название приложения: `dan4ik37`; почта поддержки — твоя → «Далее»;
   - аудитория: **Внешние** (External) → «Далее»;
   - контактная почта — твоя → «Далее» → галочка согласия → **«Создать»**.
3. Там же слева **«Брендинг»** (Branding): ссылки
   - главная страница: `https://dan4ik37.vercel.app`
   - политика конфиденциальности: `https://dan4ik37.vercel.app/privacy`
   - условия: `https://dan4ik37.vercel.app/terms`
   - авторизованный домен: `dan4ik37.vercel.app` → «Сохранить».
4. Слева **«Доступ к данным»** (Data access) → ничего не добавляй: сайту нужны только базовые `openid`, `email`, `profile`
   (их Google даёт без проверки).
5. Слева **«Аудитория»** (Audience) → **«Опубликовать приложение»** (Publish app) → подтвердить. Без этого войти сможешь
   только ты.
6. Слева **«Клиенты»** (Clients) → **«Создать клиента»**:
   - тип: **Веб-приложение**; название: `dan4ik37 сайт`;
   - **Разрешённые источники JavaScript** → «Добавить URI» → `https://dan4ik37.vercel.app`
   - **Разрешённые URI перенаправления** → «Добавить URI» → вставь ровно:
     `https://zdisuowyjgqirhvcyjfq.supabase.co/auth/v1/callback`
   - **«Создать»** → появятся **ID клиента** и **Секрет клиента** → скопируй оба.

**1.2. Supabase — включить Google**
1. https://supabase.com/dashboard → проект сайта → слева **Authentication** → **Sign In / Providers** → **Google** → включи.
2. Вставь **Client ID** и **Client Secret** из 1.1 → **Save**.
3. Слева **Authentication** → **URL Configuration**:
   - **Site URL**: `https://dan4ik37.vercel.app`
   - **Redirect URLs** → «Add URL» → `https://dan4ik37.vercel.app/**` → **Save**
     (без этого адреса вход через Google будет каждый раз спрашивать «Войти как…?»).

**1.3. «Один человек — один аккаунт» (почта + Google)**
- Supabase сам соединяет вход Google с аккаунтом, у которого **та же подтверждённая почта** (настройка по умолчанию — ничего
  не трогай). `auth-links.sql` уже выполнен — он разрешает это только Google и только для своей же почты.
- **Authentication → Sign In / Providers → «Allow manual linking»** — включи (нужно для кнопки «Привязать» в профиле →
  «Способы входа»: Discord, Twitch и т. п. к уже существующему аккаунту). `auth-links.sql` уже выполнен, так что включать безопасно.

Напиши мне **«включил Google»** — я проверю с сервера (`/auth/v1/settings` → `google: true`) и пройду вход сам.

## Шаг 2. Часть 20 — ❤ на сайте у роликов и стрима (1 минута)

Supabase → **SQL Editor** → New query → вставь из файла `community.sql` кусок **от строки `-- ЧАСТЬ 20` до конца файла**
(или весь `community.sql` — он безопасен для повторного запуска) → **Run**.
Что делает: ❤ у ролика и у сегодняшнего стрима — один от человека, повторно — убрать; кто поставил — не видно никому, только
число; наград за ❤ нет. Проверка (сделаю сам): `rpc part20_info` → `{"ok":true,"v":1}`.

## Шаг 4. Проверить самому (с телефона)

1. Открой сайт **в Chrome или Safari** (не из Telegram): главная → любой ролик → **❤ Нравится** → **«Продолжить с Google»** →
   выбери аккаунт → вернёшься к тому же ролику, ❤ стоит.
2. Новый аккаунт: окошко «Добро пожаловать» — ник и год → «Готово».
3. Тот же ролик из Telegram: вместо Google будет «Открыть в браузере» — это правильно (Google сам запрещает вход во встроенных браузерах).
