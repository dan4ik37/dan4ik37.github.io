## «Подземье» (#/games/podzem, js/games/podzem*.js; агент 15.10.2026) — своя песочница сбоку, как Террария
- Владелец 15.10: «свою террарию с поддержкой модификаций, стабильнее и лучше, с оптимизацией и бесконечной генерацией». Файлы:
  podzem-core.js (общее для потока и страницы: клетки, генерация, свет, жидкости, столкновения, упаковка; PZ_CORE — в Worker через
  toString, в node — require), podzem-gl.js (атлас 1024² кодом + WebGL2: чанк 64×64 = один квадрат, данные — текстуры RGBA8UI; все
  сэмплеры highp), podzem-ui.js (панель, вещи/крафт, меню, телефон), podzem-mods.js (моды), podzem.js (игра, шаг 1/60). Нет WebGL2 — заглушка.
- Мир бесконечный: поверхность ≈ y 200, пещеры, руды по глубине, озёра, лава ~1180; 4 биома; генерация и свет — в потоке; жидкости и
  песок — только у героя, с бюджетом (вода + лава → обсидиан). Чанки из потока — по 2 за кадр. 83 предмета, 45 рецептов, 7 видов
  мобов, 2 босса («Желейный великан», «Ночной филин»), «Проводник». Герой — свой персонаж D37Sprite сбоку с предметом в руке.
  Управление: клавиатура и мышь, геймпад, телефон (джойстик + кнопки). ЦП ~0,3–0,5 мс на кадр, 7–11 вызовов отрисовки.
- Сохранение: IndexedDB d37-podzem (только изменённые чанки, RLE) + журнал d37_podzem_journal при уходе со вкладки; экспорт/импорт.
- Моды: docs/MODS.md — ОБЩАЯ спецификация (tiles/voxel/both, API 1; раздел 7 — для «Кубомира»), примеры mods/podzem/ruby-glow (JS) и
  starfall (Lua). Песочница: iframe (CSP без сети) → Worker; Lua — js/engine/lang-lua.js. 400 действий на событие, 600/с; завис > 3 с
  или 5 ошибок — мод выключен, игра работает. Моды — на мир.
- Сайт: ключи podzem (рекорд глубины, без XP), podzem_boss1/2 (XP 6/10), монеты за босса 10/20 (coin_run_cap 20). SEO /games/podzem
  («игра как Террария онлайн»), без интернета, 12+. Кооп — план docs/PODZEM_COOP_PLAN.md. Тест: node scripts/tiles-test.cjs (199);
  в браузере GAME_IMPL.podzem._test (state, tp, give, time, god, boss, mob, perf).
- Свет (фаза 2, 15.10; переделан 22.10 — владелец: «огонь выходит за пещеру»): relight() в podzem-core.js — цветной свет волной от
  источников: воздух ×0,89, полублок ×0,76, вода — синий дальше красного, лава ×0,7; в непрозрачный блок свет входит только гранью
  (×0,62), в толще ×0,22 (небо ×0,56 — LDEEP), из камня в воздух — только своё свечение блока: сквозь стену в 1 блок не светит (LCUT 4,
  LR 32). Ореол огня — в шейдере по карте света (shade2d s2scatter, только в открытых пикселях — за стеной его нет; SCAT по набору
  0 / .26 / .36 / .44), факел мерцает (s2flick), руды/грибы/кристаллы — своим цветом. podzem-gl.js: шейдер клеток HQ (q 0…3 из

- Огонь и «живой» свет (22.10, podzem.js): пламя — SPR.flame (8 кадров) у факелов, печей и факела в руке; блики — плоский буфер GLR
