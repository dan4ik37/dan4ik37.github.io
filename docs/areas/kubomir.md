## «Кубомир» (#/games/kubomir, js/engine/voxel*.js + js/games/kubomir*.js; агент 15.10.2026) — свой мир из кубиков, как Майнкрафт
- Движок: voxel.js (реестр, чанк 16×16×128, Uint16 вид|состояние<<12, луч, столкновения), voxel-tex.js (текстуры 32×32 кодом —
  V.TEX; предметы-спрайты рисуются 16×16 и увеличиваются ×2; пакеты текстур игрока 16/32/64 → V.TEX),
  voxel-gen.js (мир по зерну: 10 биомов, реки, пещеры, ущелья, руды, озёра, деревья; одно зерно — один мир), voxel-mesh.js (свет
  3×3 чанка, «жадная» сетка с AO), voxel-worker.js + voxel-stream.js (потоки, подгрузка по дальности, выгрузка), voxel-render.js
  (Ламберт + свой свет, массив текстур WebGL2 / атлас WebGL1, пул, сдвиг начала координат 768; код травы E.FOLIAGE_A — только если
  движок его знает), voxel-store.js (IndexedDB «d37-kubomir»: миры, только правки чанков, моды; журнал при закрытии вкладки; .kubomir).
- Игра: несколько миров, выживание (мирно/легко/обычно) и творчество, инструменты 5×4, верстак, печь, сундуки, двери, лестницы,
  факелы, вода, песок, день/ночь, мобы (kubomir-ents.js), окна вещей (kubomir-ui.js), 1-е/3-е лицо, мышь/геймпад/телефон,
  ⚙️ «🧊 Кубомир» (дальность; телефон — 6), F3, Enter — команды (/help). В браузере: GAME_IMPL.kubomir._test (state, give, command,
  aim, use, dig, save). Возраст 6+; SEO /games/kubomir («как Майнкрафт» — только сравнение, FAQ «Это Майнкрафт? Нет»).
- Награды — только «Выживание»: достижения → D37Coins.run('kubomir', n, 'kb:'+id) (coin_run_cap 15), XP — game_win_xp 4,
  game_score_cap 30 (счёт = число достижений). Нужны games-more.sql и coins.sql «ещё раз».
- Моды — ОБЩИЙ формат с «Подземьем» (docs/MODS.md, раздел 7): общие поля переводятся (прочность × 0,015 с, свет → яркость, глубина
  от моря y 52), свои поля 3D — новыми ключами. kubomir-mods.js — окно «🧩 Моды» (IndexedDB, .d37mod/zip/папка/mod.json, примеры
  Рубины/Батут/Кристаллы), моды на мир и в файле мира. Песочница — iframe + CSP без сети → Worker; 400 действий за событие, 600/с;
  5 ошибок / ошибка запуска / завис 3 с — выключен.
- Замер: дальность 8 — 59 FPS, ЦП 4,3 мс, 452 вызова; 12 — 6,0 мс, 574. Офлайна и коопа нет (план коопа — хозяин мира, как net.js).
  Тест: node scripts/voxel-test.cjs (209, с scripts/voxel-test-mods.cjs; проверка «завис» зависит от времени — под нагрузкой
  других процессов может упасть, повторить).
- Свет (15.10, «плохая графика»): цветной свет блоков по каналам 0…255, кривая по самому яркому каналу (оттенок не меняется),
  факелы мерцают; лампы движка у ближних источников (kubomir-light.js: high 8 / mid 4 / low 0), туман в пещере; шейдер не
  собрался — простой режим (VR.safe). Сетка чанка — слои V.LAYERS (solid, cutout, water, foliage, glass) с метками материалов для
  «паков» шейдеров движка (VR.onShader / setLayerMaterial; voxel-render.js правит только агент «Кубомира»). Наборы шейдеров
  (docs/SHADERS3D.md): вырезное по альфе пишет код травы движка (E.FOLIAGE_GLSL — без пятен AO), листва и трава качаются ветром
  движка (R.wave на слоях foliage/cutout → D37_WAVE; сила и направление — E.GFXU.wind; у «Обычных» стоят; свой сдвиг — в
  единицах сетки, кусок ветра движка в project_vertex снят: он для моделей без масштаба, а сетка чанка — в масштабе 1/16).
