# Свои эмодзи и стикеры с сервера сообщества (T-167)

> Сейчас ВЫКЛЮЧЕНО. Включает владелец сайта, когда решит открытые вопросы (внизу).

## Как это работает
1. Владелец или модератор сообщества кладёт картинки на **свой** сайт (свой «мини-сервер»).
2. В чате: «🎉 Фишки сервера» → «🌐 С сервера сообщества» → пишет свой узел (например `pics.example.com`, до 3 узлов) и адрес картинки.
3. Наш сервер **один раз** скачивает файл и проверяет его:
   - только `https://` и только разрешённый узел;
   - без перенаправлений, ответ не дольше 5 секунд;
   - только PNG, GIF, WebP или JPEG (SVG и прочее — нет), тип узнаём по самим байтам;
   - эмодзи до 256 КБ и до 256×256, стикер до 512 КБ и до 512×512;
   - нужен заголовок CORS (как его включить — ниже).

   Наш сервер запоминает «отпечаток» файла (sha-256), размер и тип.
4. Человек из команды сайта смотрит картинку и одобряет или отклоняет. Автоматической проверки содержимого нет.
5. У участников сообщества браузер скачивает картинку и сверяет отпечаток. Если файл поменяли после проверки, картинка **не покажется** (останется `:имя:`).

Важно знать:
- Ваш сервер видит адреса в сети (IP) тех, кто смотрит картинки. Поэтому сайт сначала спрашивает согласие участника. Гостям и на открытых страницах картинки не грузятся.
- Поменяли картинку — добавьте её заново под новым именем, она снова пройдёт проверку.

## Мини-сервер за 5 минут
Нужна папка с картинками и один заголовок:

```
Access-Control-Allow-Origin: https://dan4ik37.vercel.app
```

Без перенаправлений: адрес должен сразу отдавать файл.

**GitHub Pages / Netlify / Cloudflare Pages.** Положите папку `pics/` в репозиторий.

Netlify и Cloudflare Pages: добавьте файл `_headers`:
```
/pics/*
  Access-Control-Allow-Origin: https://dan4ik37.vercel.app
  Cache-Control: public, max-age=86400
```
GitHub Pages свой заголовок поставить не даёт, но сам отдаёт `Access-Control-Allow-Origin: *` — так тоже подходит.

**Свой компьютер или сервер (Node.js, без пакетов):**
```js
// server.js — запуск: node server.js (нужен https: через Caddy / Cloudflare Tunnel / хостинг)
const http = require('http'), fs = require('fs'), path = require('path');
const DIR = path.join(__dirname, 'pics');
const TYPES = { '.png': 'image/png', '.gif': 'image/gif', '.webp': 'image/webp', '.jpg': 'image/jpeg', '.jpeg': 'image/jpeg' };
http.createServer((req, res) => {
  const name = path.basename(decodeURIComponent((req.url || '').split('?')[0]));
  const type = TYPES[path.extname(name).toLowerCase()];
  const file = path.join(DIR, name);
  if (!type || !fs.existsSync(file)) { res.writeHead(404); res.end(); return; }
  res.writeHead(200, {
    'Content-Type': type,
    'Access-Control-Allow-Origin': 'https://dan4ik37.vercel.app',
    'Cache-Control': 'public, max-age=86400',
    'X-Content-Type-Options': 'nosniff',
  });
  fs.createReadStream(file).pipe(res);
}).listen(8080);
```
Снаружи адрес должен быть `https://` (обычный порт 443). Например, `https://pics.example.com/smile.png`.

**Без своего сервера.** Загрузите картинку прямо на сайт: «🎉 Фишки сервера» → «😀 Эмодзи» / «🖼 Стикеры» → «📁 Файл». Сайт сам уменьшит картинку. У сообществ картинки тоже проходят проверку командой сайта.

## Решения владельца сайта (пока не приняты)
- Включать ли вообще (`site_config 'ext_media' = 'on'` + в коде `EXT_PICS = true`).
- Для каких сообществ: только 18+ или детские тоже после проверки модератором.
- Лимиты: размер, пиксели, 50 картинок на сообщество, 10 в день.
- Нужна ли строка согласия про IP у участника (сейчас она есть).
