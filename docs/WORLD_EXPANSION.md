## Решения координатора / владельца (не терять)
- Прямоугольник района участков x −133…−12, z −137…−12 — НЕ трогать (дорога/телепорт к арке — можно). Район становится мирным
  (дома для всех возрастов, как «Аватария»); набеги и оборона переезжают в военные базы боевой зоны. Систему баз (главарь,
  звания, ангары, оборона, технологии, набеги) делает агент набегов — по разметке PLOTS.
- Каждое здание входимо; интерьеры — модуль движка interior.js (не код игры); разрушения — позже, отдельной задачей движка
  (детали с номерами уже есть только в боевой зоне; детский город — никогда не ломается).
- Транспорт — общий модуль движка («чтобы можно было делать везде»): машины — данные, режим 'arcade' по умолчанию, шов
  'rapier'; сеть 'vh' как 'st' (ведёт водитель, остальные проверяют потолок скорости и телепорты; 5/с через Supabase);
  крючки экономики (топливо, груз), ИИ-водителей (follow), гаражей (spawn/despawn). Студия — потом («Место водителя»).
- Только стандартные материалы движка, без своих шейдеров; временные файлы — только на диске E (E:\claude-tmp\world).
- Перед каждым коммитом: `node scripts/world-zones-test.cjs`, `engine-test.cjs`, `mirplay-test.cjs`, `base-test.cjs`.
