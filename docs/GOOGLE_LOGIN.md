# Как включить «Войти через Google» (≈10 минут)

Кнопка на сайте уже готова — она появится в окне входа сама, как только Google будет включён в Supabase.
Зачем: сейчас регистрация — почта, пароль и подтверждение письмом; много людей на этом уходят.
Через Google — один клик, без пароля и без письма.

## Шаг 1. Google Cloud — получить «ID клиента» и «Секрет»

1. Открой https://console.cloud.google.com → вверху выбери проект (или «Создать проект», название `dan4ik37-site`).
2. Слева «API и сервисы» → **«Окно запроса доступа OAuth»** (OAuth consent screen):
   - тип пользователей — **Внешний** → «Создать»;
   - название приложения `dan4ik37`, почта поддержки — твоя, почта разработчика — твоя → «Сохранить и продолжить»
     (остальные шаги можно пропустить кнопкой «Сохранить и продолжить»);
   - в конце нажми **«Опубликовать приложение»** (Publish app), чтобы входить мог любой, а не только ты.
3. Слева «Учётные данные» (Credentials) → **«Создать учётные данные» → «Идентификатор клиента OAuth»**:
   - тип приложения — **Веб-приложение**;
   - «Разрешённые URI перенаправления» → «Добавить URI» → вставь ровно:
     `https://zdisuowyjgqirhvcyjfq.supabase.co/auth/v1/callback`
   - «Создать». Появятся **ID клиента** и **Секрет клиента** — скопируй оба (окно можно не закрывать).

## Шаг 2. Supabase — включить Google

1. Открой https://supabase.com/dashboard → проект сайта → слева **Authentication** → **Sign In / Providers** (или Providers).
2. Найди **Google** → включи переключатель → вставь **Client ID** и **Client Secret** из шага 1 → **Save**.
3. Там же слева **URL Configuration**:
   - **Site URL**: `https://dan4ik37.vercel.app`
   - **Redirect URLs** → «Add URL» → `https://dan4ik37.vercel.app/**` → Save.

## Шаг 3. Проверить

Открой сайт → «Войти» — сверху появится белая кнопка **«Войти через Google»**. Нажми, выбери аккаунт —
вернёт на сайт уже вошедшим и откроет профиль. Ник у новых аккаунтов будет вида `user_ab12cd` — его меняют в профиле.

Напиши «включил Google» — проверю с сервера, что всё работает.
