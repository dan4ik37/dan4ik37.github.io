# Аудит платежей (фаза 0 мастер-инструкции, 21.10.2026)

Это не юридическая и не налоговая консультация: статус (самозанятый, ИП), оферта, возвраты и работа с несовершеннолетними
подтверждаются у специалиста. Здесь — только то, что есть в коде, и где он расходится с инструкцией.

## 1. Какие денежные потоки есть
| Поток | Как устроен | Работает сейчас? |
|---|---|---|
| Донат DonationAlerts → VIP | Зритель донатит на странице DonationAlerts, указывает свой логин сайта. `api/vip-sync.js` (раз в несколько минут по пингу сайта и раз в сутки по Vercel Cron, замок в базе) забирает донаты и зовёт SQL `credit_donation`: 100 ₽ = месяц VIP, остаток копится (`vip-balance.sql`, `vip-secure.sql`). Не нашёлся логин — заявка «Задонатил, а VIP не пришёл?» (`vip-claims.sql`: авто-привязка при ≤ 2 опечатках, иначе админ). | **Да** |
| Донат DonationAlerts → 💎 | Тот же путь; если человек выбрал в магазине «донат → кристаллы» (`premium_wallet.donate_mode = 'gems'`): 1 ₽ = 1 💎, от 500/1000/2000 ₽ +10/20/30 %. | **Да** |
| Карта → 💎 | `api/pay.js`: TipTop Pay (HMAC-подпись), Freedom Pay (подпись md5), ссылка Kaspi (админ подтверждает вручную); заказ только с галочкой «платит взрослый или разрешил»; лимиты 3000 ₽ в сутки / 10 000 ₽ за 30 дней, подросткам меньше, детям до 13 — нельзя. | **Нет** — ключей нет, `/api/pay?a=config` → `methods: []` |
| 💎 внутри сайта | VIP 1/3/12 мес, VIP в подарок, обмен на 🪙, вещи персонажа, кабинет рекламы, буст сообществ (позже — «Набеги»). Списание только на сервере (`premium_spend` / `premium_add`), журнал `premium_ledger`. | Да |

Домены: оплата картой и уведомления провайдеров — только `https://dan4ik37.vercel.app/api/pay` (провайдеру заявлять этот домен).
Старый адрес `dan4ik37.github.io` перенаправляет на vercel.app. Реквизиты продавца — одно место `api/_lib/seller.js` (сейчас
заглушки «уточняется»). Страницы `/terms`, `/refund`, `/contacts` есть (шаблон — показать юристу).

## 2. Расхождения с инструкцией
1. ⚠️ **VIP и 💎 за донаты DonationAlerts** — инструкция (раздел 6): до оформления статуса донаты — без встречной выдачи, VIP и 💎 —
   только за активность. Сейчас донат даёт VIP или 💎. **Решает владелец.** Готовим выключатель (по умолчанию — как сейчас,
   ничего не ломаем): «Донаты дают VIP/💎: да / нет»; при «нет» — донат только благодарность, уже выданный VIP остаётся.
2. ⚠️ **Согласие на обработку персональных данных** при оплате — отдельной галочки нет (есть галочка «платит взрослый»). Добавить
   до включения любой оплаты картой.
3. ⚠️ **Возраст платежей**: сейчас карта закрыта до 13 лет, 13–17 — лимиты и галочка. По инструкции: до 14 — никаких платежей,
   14–17 — только с ПОДТВЕРЖДЁННЫМ согласием родителя и лимитом (нужен механизм согласия — фаза 1). Донат DonationAlerts по
   возрасту сайт не проверяет (это чужая страница) — ещё один довод решить п. 1.
4. ✅ Деньги начисляются только по проверенной подписи провайдера, без повторов (`premium_payments`: провайдер + номер — одно
   начисление), возврат — `premium_refund` (потратил — долг). Вывода 💎 в деньги нет.
5. ✅ Пока статус не оформлен, оплата картой не включена (ключей нет) — совпадает с инструкцией.
