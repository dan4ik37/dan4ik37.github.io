Код — age.sql, community.sql (без новых файлов), выключатель site_config 'kidsafe'. Тесты PGlite на каждую пару групп.

Красная линия инструкции: «Два мира: детский (до 18, а также возраст не указан или не подтверждён) и взрослый (18+ подтверждено
надёжным способом). Данные и общение разделены на уровне базы (поле realm и политики RLS), каналов реального времени, игровых
серверов, поиска и P2P. Внутри детского мира полосы чата: до 9, 9–12, 13–15, 16–17, общение со своей и соседними. До 9 лет
чат выключен до согласия родителя. До 14 лет платежей нет. В 14–17 только с подтверждённым согласием родителя и лимитом. Хранить
только результат проверки возраста, без фото и документов.»

Что есть: год рождения по желанию (`user_age`, видит только сам человек), группы `age_group_of` (child до 13 / teen 13–15 /
teen16 16–17 / adult / unknown), метки 0+…18+, реклама по возрасту. Разделения общения нет: чат, ЛС, мир, игры — общие.

## 1. Решения (одной строкой, как просит инструкция)
- Мир (`realm`): `adult` — только у кого есть запись надёжной проверки 18+; у всех остальных — `kids`. Поставщика проверки пока
  нет → сейчас все в детском мире; взрослый мир откроется сам, когда появится проверка (модуль с заменяемым поставщиком).
- Полосы детского мира (`band`): b0 — до 9, b1 — 9–12, b2 — 13–15, b3 — 16–17, b4 — «18+ по году, без проверки». Общение — со
  своей и соседними: b0↔b1, b1↔b2, b2↔b3, b3↔b4. b4 нужна, чтобы взрослые без проверки не попадали к младшим.
- Возраст не указан: читать можно (видит b1–b2, как у сайта 12+), писать — только после выбора года (одна кнопка, год видит
  только сам человек). Гость без входа — так же.
- До 9 лет (b0): чат, ЛС, звонки и общий чат мира выключены до согласия родителя; игры и одиночные режимы — как были.
- Команда сайта (admin, moderator) и бот — видны всем полосам и модерируют все (официальные сообщения); владелец канала тоже.
- «Большой город 18+» — контента 18+ в нём нет (без алкоголя, азарта и откровенного) → метка 16+ внутри детского мира (b3, b4);
  настоящий взрослый мир — когда будет проверка. Ролики 18+ (кейсы) — только взрослому миру → сейчас никому (обложка без
  «взрослый разрешил»), из лент и поиска — убраны (уже так для несовершеннолетних).
- Платежи: до 14 — нет; 14–17 — только с подтверждённым согласием родителя (механизма пока нет → закрыто); 18+ по году без
  проверки — как сейчас (лимиты). Донат DonationAlerts сайт не проверяет — решение по нему у владельца (docs/payments-audit.md).
- Всё — за выключателем `site_config.realms` ('on' / 'off'), по умолчанию 'on' после проверки на PGlite; 'off' — как раньше.

## 2. Где разделять
- **База (RLS)**: `messages` (общий чат), `community_messages`, ЛС, заявки в друзья, участие в сообществах (сообщество с меткой
  возраста уже не видно младшим), поиск людей. У сообщения — `realm` и `band` автора на момент отправки (триггер, не браузер);
  читать — только если полоса читателя соседняя или своя (или команда сайта). Функции: `realm_of(uid)`, `age_band_of(uid)`,
  `band_ok(a, b)`. Где жить коду: возраст — `age.sql`, чат и сообщества — `community.sql` (новых SQL-файлов не заводим).
- **Реальное время**: Supabase Realtime `postgres_changes` уже слушается через RLS; каналы presence/broadcast (мир `mir-<N>`,
  «🌍 Весь мир», «кто онлайн», комнаты игр, звонки, студия) — имя канала с миром и полосой (`mir-k2-<N>`): разные полосы —
  разные каналы; подпись пропуском мира (`world_pass` дописать realm/band) — подделать нельзя.
- **Игровые серверы и P2P**: комнаты (`room.js`, `table.js`, `netplay.js`, `net.js`) — код комнаты действует только внутри своего
  мира и соседних полос (знакомство WebRTC идёт через тот же канал); чужую ссылку-приглашение — «эта игра для другой
  возрастной группы».
- **Поиск**: профили, сообщества, миры игроков — только свой мир; результаты поиска людей — соседние полосы.

## 3. Проверка возраста и согласие родителя (модули с заменяемым поставщиком, выключены)
- `age_verify` — только результат: uid, provider, result (adult да/нет), checked_at, без фото и документов.
- `parent_consent` — uid ребёнка, способ, проверенный взрослый (uid с age_verify adult), что разрешено (чат до 9, платежи 14–17,
  лимит), дата, отзыв. Пока поставщиков нет — интерфейс честно пишет «скоро», ничего не открывается.

## 4. Тесты (инструкция: «пользователь одного мира ничего не видит и не может записать в другом»)
PGlite: для каждой пары полос — читать/писать в общий чат, сообщества, ЛС, заявки в друзья, поиск; команда сайта видит всех;
подделка realm/band в insert не проходит; `site_config.realms = 'off'` — как раньше. Узел: имена каналов и проверка
приглашений в комнаты. Старые ссылки и сообщения не пропадают (у старых сообщений без полосы — видны b1–b3 и команде).

## 5. Порядок (агент, после «адресов», коммиты по шагам)
1. SQL и тесты (age.sql, community.sql) за выключателем. 2. Чат и ЛС в браузере (подписи «ты видишь ребят 9–15», выбор года для
записи, до 9 — объяснение). 3. Каналы реального времени, мир и комнаты игр. 4. 18+ ролики и город 16+, платежи по возрасту.
5. Заготовки проверки 18+ и согласия родителя (выключены). Владельцу — один список SQL в конце.
