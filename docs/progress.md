## 22.10 — две руки и бой (T-012; docs/COMBAT.md §1, §3, шаги 1–2: ядро js/engine/combat.js + «Кубомир»)
Решения (одной строкой):
- ПКМ: правая рука главнее (как в Майнкрафте) — блоки ставятся и со щитом в левой; левая действует, только если правой нечего делать.
- Щит, выбранный в панели, держат левой (хват «только левая»); лук — двумя руками (вещь левой убрана); лук в левой ячейке не работает.
- Удар — замах ядра боя и попадание по дуге клинка через 0,07–0,17 с (раньше — сразу); сквозь стены не бьёт; бить часто — слабо.
- Слабый удар больше не сбивает замах моба — только сильный (стойкость моба); отброс — по оружию и силе удара (раньше всегда 6).
- Топор как оружие: +2 к урону (был слабее меча и бил реже — бесполезен), выбивает поднятый щит на 2,5 с.
- Стрелы: кремень из гравия 10 %, волокно из высокой травы 25 % (как в «Подземье»); второй рецепт стрел — из булыжника (2 шт.).
- Неуязвимость игрока после урона — по шагам игры (по часам страницы первые 0,45 с после загрузки урона не было вовсе).
- player.js — в списке скриптов «Кубомира»: без него паркур T-005 не работал, если «Кубомир» открыт первым (E.grip не было).
- world3d armL — правая рука человечка (названия — для смотрящего спереди): главная вещь — в handL; эталон char-test не тронут,
  CHAR_VERSION прежняя (новые позы — только слоем o.hold, без него всё как было).
Замер (kubomir-e2e KB_MODE=perf: телефон, ЦП ×4, «средняя»; машину грузили другие агенты — пары «до/после» подряд): ЦП кадра в

## 22.10 — огонь движка во всех мирах (T-022d)
Ядро js/engine/fire.js (D37E.fire: клетки 2D/3D и детали) и пламя fx.js FX.flames; «Кубомир» (kubomir-fire.js), «Подземье»
(podzem-fire.js), боевая зона «Мира» (mir-fire.js), «Студия 3D» (studio3d-fire.js, Fire.* в 4 языках). Замеры (машина весь день под
нагрузкой других агентов — 70–96 % ЦП, числа Chrome шумные; сравнение — окнами по очереди, медианы):
- ядро (node): такт с 3000 горящими — 0,015–0,018 мс в среднем (ПК), с перекидыванием в лесу (2000 горящих) — 0,08 мс; без мусора за
  такт; 30 / 60 / 144 кадра — тот же пожар (клетки и детали; детали — в любом порядке добавления). Бюджет: «Кубомир» 180 обходов за
  такт (20 в секунду), «Подземье» 200 (30), «Мир» 512 (10), «Студия» 512 (15); горящих не больше 4096 / 4096 / 512 / 1024.
- «Кубомир», телефон (412×915, ЦП ×4, «средняя»), лес 6×6 + дом, пик 1029–1130 горящих: без огня 13,5 мс (p95 20,3) → в разгаре
  25,0 мс (p95 37,7), вызовов 251 → 273; огонь на паузе / идёт (медианы трёх): 13,9 → 16,7 мс; кадр пламени (300 очагов, ПК) — 0,14–0,33 мс,
  613 Б мусора; сеток чанков в пожаре 31,5 → 21,3 в секунду (правки огня — не чаще раза в 280 мс на чанк).
- «Подземье», телефон ×4: без огня 1,8–2,7 мс → пожар (290 горящих) медиана 2,75 мс (p95 7,7), в первые секунды большого поджога —
  7–10 мс; «живой» свет очагов — одним заливом (node: 0,11–0,31 мс на кадр в пожаре против 0,2–0,84 до); вызовов 8 → 10.
- «Мир», телефон ×4, три очага в боевой зоне (горят 36–39, языков 72–78): огонь на паузе / идёт (медианы четырёх) — 16,1 → 17,3 мс
  (худший 33,8 → 38,6); шаг (node) — 0,02 мс в среднем, 99 % — до 0,1 мс. «Студия 3D» (Chrome, ПК): 26 деталей, ЦП кадра 1,5–1,9 мс, 49 вызовов.
- Память: закрыть/открыть мир с пожаром 20 раз — «Кубомир» 106,5 → 113,3 МБ (полка 111–117), «Подземье» 20,6 → 20,5 МБ;
  дом сгорел 12 раз на одном месте («Кубомир», KB_MODE=firecycle) — 107,7 → 109,1 МБ. 10 мин игры с огнём — 0 ошибок: «Кубомир»
  (выживание, телепорты, бой, поджоги; загорелось 99, сгорело 61; память 106,8 → 179,8 МБ — в этом прогоне растёт и без огня: новые
  чанки после телепортов, сегодня без огня +30…+51), «Подземье» в Chrome (2365 действий, загорелось 1164, сгорело 999; память
  20,0 → 20,8 МБ) и в node (2400 действий). CI (ci-run): 83 прошло, 0 упало (4 «нестабильных» по времени — не огонь).
Решения (одной строкой):
- Горючесть — только по полям блоков и плиток (без списков имён): деревья T-022b и моды горят сами; поле burn главнее (и у модов).
- «Подземье» — без блока «огонь»: горящее живёт в ядре, пламя и свет — по его списку (меньше правок мира и сохранений);
  «Кубомир» — блок «огонь» (свет блоков, урон, «вместе» и сохранение — как у всех блоков).
- Сгоревший ствол — путём топора, сгоревшая опора — обрушением (D37E.support); сундуки «Подземья» не горят (в них вещи).
- 2D — «жар через клетку» (вбок ×0,35, вверх ×0,9): у среза мира вдвое меньше соседей, без этого трава гасла через 3–5 клеток.
- Случайность деталей — по ключу места, не по номеру: у игроков «Мира» зона строится в разном порядке, пожар — тот же.
- «Мир»: одно событие поджога (зерно + номер такта); догорело — ломается без рассылки; не больше 4 событий в секунду; детский
  городок, столица и Большой город — никогда (только боевая зона); своего переключателя в ⚙️ нет — мир общий (выключил у себя —
  у тебя пожар шёл бы иначе), пламя — по качеству графики.
- «Студия 3D»: по сети — только onfire (предел своих свойств net.js — 16), burn и fire — у хозяина; вечный огонь — onfire 9.
- Пламя — смешивание «поверх с подсветкой»: на светлом небе оранжевое (сложением было белым).
- Откат одной строкой: KubomirFire.ON, PZFire.ON, MirFire.ON, ON в studio3d-fire.js.
Не сделано (очередь): пожарные в «Городе» (работа РП), огонь от молнии и фар в «Мире», ведро/огнетушитель и дождь в «Подземье» (там нет
погоды), чернение деревьев «Мира» (сейчас пламя и дым, догорело — ломается), «вместе» с огнём в двух браузерах (проверено в node),
настоящий телефон.
