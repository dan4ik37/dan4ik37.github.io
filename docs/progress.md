## 22.10 — две руки и бой (T-012; docs/COMBAT.md §1, §3, шаги 1–2: ядро js/engine/combat.js + «Кубомир»)
Решения (одной строкой):

- Щит, выбранный в панели, держат левой (хват «только левая»); лук — двумя руками (вещь левой убрана); лук в левой ячейке не работает.

- Слабый удар больше не сбивает замах моба — только сильный (стойкость моба); отброс — по оружию и силе удара (раньше всегда 6).
- Топор как оружие: +2 к урону (был слабее меча и бил реже — бесполезен), выбивает поднятый щит на 2,5 с.

- Неуязвимость игрока после урона — по шагам игры (по часам страницы первые 0,45 с после загрузки урона не было вовсе).

- world3d armL — правая рука человечка (названия — для смотрящего спереди): главная вещь — в handL; эталон char-test не тронут,
  CHAR_VERSION прежняя (новые позы — только слоем o.hold, без него всё как было).
Замер (kubomir-e2e KB_MODE=perf: телефон, ЦП ×4, «средняя»; машину грузили другие агенты — пары «до/после» подряд): ЦП кадра в
