# Новые монстры для «Кубомира» и «Подземья» (замысел, 16.10.2026)

Владелец: «сложность можешь оставить или даже посложнее, и придумать новых монстров». Сложность «💀 Сложно» в «Кубомире»
сделана 16.10: мобов до 9 рядом, бьют ×1,5, появляются чаще, голод убивает, вещи после смерти выпадают.

Монстры — общий набор для обеих игр (CLAUDE.md, задача 16): одно описание существа, 3D-модель кодом (как человечки world3d) и
спрайты сбоку из неё (как char2d). Делать после сброса недельного лимита (21.10). Названия и вид — свои; механики похожих игр —
только как идеи.

## Обычные (по местам)
| Существо | Где и когда | Чем опасно / как победить |
|---|---|---|
| **Паучок-лазун** | ночь, пещеры | лезет по стенам и потолку, прыгает сверху; боится света факелов |
| **Скелет-лучник** | ночь, глубина | стреляет издалека, держит дистанцию; прячься за блоками, подходи зигзагом |
| **Пузырь-взрывун** | ночь, болота | раздувается и лопается рядом, рушит блоки; бей издалека или уходи |
| **Тень** | только в полной темноте | невидима, пока не подойдёт; растворяется на свету — повод ставить факелы |
| **Пещерный червь** | глубоко в камне | прогрызает блоки, вылезает из стены; слышно гул заранее |
| **Мимик-сундук** | подземелья | притворяется сундуком; кусает, если открыть, — внутри хорошая добыча |
| **Ледяной призрак** | снег, ночь | замедляет холодом; горячая еда и огонь помогают |
| **Песчаный скорпион** | пустыня, днём | ядовит (урон со временем); прячется в песке |
| **Болотник** | болота | тянет в воду; не стой у края |
| **Летучая медуза** | подземные озёра | бьёт током рядом с водой; держись суши |
| **Каменный голем** | горы | медленный, очень крепкий; кирка бьёт его сильнее меча |

## Боссы (с этапами боя, предупреждением атак, наградой)
| Босс | Призыв / где | Этапы |
|---|---|---|
| **Королева пауков** | логово в пещерах | 1) паутина на полу и стенах; 2) зовёт паучков; 3) прыжки с потолка |
| **Лавовый змей** | слой лавы | ныряет в лаву и выныривает с огнём; бить, когда на виду |
| **Хозяин кристаллов** | кристальные пещеры | щиты-кристаллы надо разбить; потом лучи по кругу |
| **Король тыкв** | событие «Тыквенная ночь» | волны тыквоголовых, сам — в конце |

## Опасные ночи (события)
- **Кровавая луна** — раз в 7 игровых дней: мобов вдвое больше, у дверей ломятся.
- **Тыквенная ночь** — осенью, с наградами-украшениями.
- **Метель** — в снежных краях, видимость меньше, призраки чаще.

## Правила
- Возраст: мультяшно, без крови («Кубомир» 6+, «Подземье» 12+); пугать — но не жестоко.
- Частота появления — по часам игры (не по кадрам), только вне экрана, с потолком рядом.
- Мобы из модов — тот же формат (docs/MODS.md); «Бестиарий» — кого встретил, чем бить, что выпадает.
