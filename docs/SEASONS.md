## 1. Правила владельца (как есть)

- Времена года быстрые, как в Симс: каждое — около реальной недели, большую часть года.
- Вокруг Нового года — ВСЕГДА зима: декабрь и январь.
- Ноябрь — ВСЕГДА осень («осень приходит за месяц, обязательным событием»).
- В 00:00 Нового года — праздник во ВСЕХ мирах, у каждого — в его МЕСТНУЮ полночь. «У Китая свой Новый год, у других —
  свой»: лунный Новый год (таблица 2026–2040), Наурыз 21–23 марта (владелец живёт в Казахстане), расширяемый список праздников.
- Февраль–октябрь — целыми быстрыми кругами: весна сразу после закреплённой зимы, конец октября перетекает в закреплённую
  ноябрьскую осень.
- Новогоднее задание (как адвент-календарь) — висит ВСЕГДА с 1 декабря до 1 января: карточка во всех мирах (свернуть можно,
  убрать нельзя), полоса на сайте; отсчёт до Нового года и задание дня из таблицы (31 задание); прогресс — пока в браузере; в
  00:00 1 января по местному — праздник.
- Новые года других стран — данными, у каждого своё поздравление и стиль; уважительно: торжественные — только поздравление,
  без салюта.

## 2. Календарь — точная формула

Сезон считается по «времени мира» — Москва, UTC+3 (`E.climate.ZONE = 180`, как «день по МСК» у остального сайта): у всех
игроков общего мира одно время года (иначе у друзей рядом был бы разный снег). Праздники — по МЕСТНОМУ времени игрока.

Фаза года φ ∈ [0, 4): 0…1 — весна, 1…2 — лето, 2…3 — осень, 3…4 — зима; сезон = ⌊φ⌋, прогресс = дробная часть.

- **Декабрь–январь** (закреплённая зима): φ = 3 + (t − 1 дек 00:00) / (62 сут). 1 декабря — начало зимы, 1 января — середина
  (самый холод), 31 января 24:00 — φ = 4 ≡ 0.
- **Февраль–октябрь** (быстрые круги): φ = (38 · (t − 1 фев 00:00) / L) mod 4, L — суток от 1 февраля до 1 ноября (273, в
  високосный год 274). 38 сезонов = весна, лето + 9 полных кругов (осень, зима, весна, лето): первая — весна (сразу после
  января), последняя — лето. Сезон длится L/38 ≈ 7,18 суток (7 сут 4 ч 25 мин; в високосный — 7,21).
- **Ноябрь** (закреплённая осень): φ = 2 + (t − 1 ноя 00:00) / (30 сут).

На всех стыках φ непрерывна: 31 янв → 1 фев (4 ≡ 0, зима → весна), 31 окт → 1 ноя (38 ≡ 2, лето → осень), 30 ноя → 1 дек
(3, осень → зима). Температура, листва, снег — гладкие функции φ, поэтому смена сезона — не скачок, а плавный переход.

Режимы мира (`mode`):
- `calendar` — общий мир: формула выше по реальному времени (по умолчанию в «Мире Денчика», студии и «Кубомире»);
- `cycle` — по игровым дням: N игровых суток на сезон (`days`, 1–60), φ = (сутки + час/24) / N mod 4, начало — весна;
- `fixed` — один сезон (`season`) — погода идёт, сезон стоит;
- `off` — без времён года и погоды (ясно, лето, +20).
Погода — `auto` (по расписанию) или одна из `E.climate.STATES` (стоит всегда).

## 4. Погода (детерминированно: зерно мира + время, без сети)

Часы погоды w («погодные часы»): `calendar` — w = реальные минуты / 7,5 (1 погодный час = 7,5 мин); `cycle` — w = игровые
часы (сутки × 24 + час). Сутки делятся на части по 6 w-часов (в общем мире — 45 мин). В каждой части по хешу (зерно, номер
части) — событие или нет: осадки (длина 1,5–4,5 w-ч, сила 0,5–1, края по 0,5 w-ч), гроза (лето), туман (утро, море, осень),
зной (лето, пустыня/степь, день). Вероятность — от сезона и климата места. Фронт идёт с запада на восток: w в точке
сдвинута на x / 4000 w-ч. Фон облачности — плавный шум по w.

Климаты места (`climateAt(x, z)` даёт игра; иначе `temperate`): `temperate`, `steppe` (Казахстан: сухо, ветер, жаркое лето,
морозная зима), `mountain` (холоднее, снежнее), `desert` (жарко, сухо: осадки ×0,15), `sea` (ветер, туманы), `snow`
(тундра), `tropic`. Вид осадков — по температуре В ЭТОЙ ТОЧКЕ: ≤ +0,5° — снег, ≥ +2,5° — дождь, между — мокрый снег; один
фронт: в горах снег, в долине дождь.

Состояние (`STATES`): `clear`, `cloudy`, `overcast`, `rain`, `thunderstorm`, `snow`, `blizzard`, `fog`, `heat` — по силе
частей (гроза > метель > снег > дождь > туман > зной > пасмурно > облачно > ясно). Грозы и метели мягкие (сайт для детей):
гром тихий и далёкий, вспышка не ослепляет, без страшного.

Температура, °C: сезон (средняя климата + размах · cos(2π(φ − 1,5)/4): пик — середина лета, минимум — середина зимы) + сутки
(± по климату, пик в 15:00, облака сглаживают) + высота (`lapse` на единицу над `seaY`) + погода (дождь −3, снег ≤ +1,
пасмурная ночь теплее, зной +6) + медленный шум ±2. «Ощущается»: ветро-холодовой индекс (Канада, T ≤ 10°, ветер ≥ 5 км/ч)
и кажущаяся температура (BoM Австралии) в жару. Ветер, м/с: климат (море и степь — сильнее) + погода (гроза, метель) +
порывы; направление медленно поворачивается.

Накопители (из прошлого погоды в этой точке — интеграл по последним 30 w-часам, шаг 0,5): мокро (дождь — быстро, сохнет за
~1,5–3 w-ч, в мороз не сохнет), лужи (медленнее), снег на земле (растёт в снегопад ~3 w-ч до полного, тает от +1°: быстрее в
тепло и дождь), лёд на воде (замерзает после ~4 w-ч ниже −2°, тает от +1°; ходить — с `ice ≥ 0,8`).

## 5. API

```js
const C = D37E.climate;
C.calendar(ms, { tz })   // { season, phase (0…4), progress, label, year, month, day, hour, holidays: [{ id, phase, … }], next }
C.holidays(ms, { tz })   // активные праздники с фазами pre / burst / day
C.HOLIDAYS, C.STATES, C.SEASONS, C.CLIMATES
const W = C.world({ seed, mode: 'calendar'|'cycle'|'fixed'|'off', days, season, weather: 'auto'|STATE, climateAt(x, z),
                    lapse, seaY, hourAt(ms), gameTime() → { day, hour } })
W.at(x, z, ms, y)        // { season, phase, state, temp, feels, cloud, rain, snow, hail, thunder, fog, heat, wind, windDir,
                         //   wet, puddle, snowCover, ice, leafTint, bare, climate, humid }
C.use(W); C.at(x, z, ms, y)   // то же для «текущего» мира
C.exposure(state, { clothes, inside, wet, moving, near }) → { cold, heat, wet }   // для персонажей (Симс — после 21.10)
C.on('holiday' | 'season' | 'weather', fn) → отписка; C.tick(ms) — проверить смену (зовут celebrate.js и attach)
```

Картинка: `const X = C.attach(R, opts)` (js/engine/precip.js) — одна строка подключения в любой 3D-игре:
```js
X = D37E.climate.attach(R, {
  world: W | { seed, mode, … },           // мир погоды (или настройки для C.world)
  where: () => [x, y, z],                 // где игрок (погода и частицы — вокруг камеры, состояние — здесь)
  skyTop: (x, z) => y,                    // где кончается небо в столбе (крыша, дерево) — капли под крышей не идут
  water: (x, z) => y | -Infinity,         // уровень воды (круги дождя, лёд)
  origin: () => [ox, oz],                 // сдвиг начала координат (как у «Кубомира»), по умолчанию [0, 0]
  hour: () => R.lighting.time,            // время суток игры
  sound: D37E.audio(),                    // шум дождя, ветер, гром
  occlusion: true,                        // карта «что над головой» для снега и мокрого на поверхностях (крыши, интерьеры)
});
X.frame(dt) каждый кадр (до R.render); X.state; X.vis (сглаженное); X.force(state | null); X.setWorld(W); X.iceAt(x, z);
X.stats(); X.dispose()
// ещё: particles: false — свои частицы у игры («Кубомир»), sky: false — небо и туман игра темнит сама; D37E.precip.physTop(ph, yTop)
// — skyTop из физики движка (луч сверху, кэш по клеткам); D37E.climate.leaf(материал, 'grass' | 'leaves' | 'needles')
```
Настройки игрока (⚙️ «🌦 Погода», js/core/celebrate.js): `wxFx` (эффекты погоды), `wxAmt` (частицы, %), `holidays` (салют и
поздравления; новогоднее задание остаётся).

## 6. Картинка (все 3D-игры)

- Небо, туман, свет: `R.setWeather({ cloud, rain, snow, fog, heat, storm, flash })` — render.js после `E.skyModel` делает
  небо серее и темнее, солнце бледнее (тени мягче, но castShadow не трогаем — иначе пересборка шейдеров), туман ближе и цвета
  туч, в снегопад — белёсый, в зной — дымка и тёплый тон. Без погоды — ровно как раньше.
- Частицы (precip.js, пулы вокруг камеры, как в «Кубомире»): дождь — отрезки, снег — точки-хлопья, град — короткие яркие
  отрезки, брызги, круги на воде (`InstancedMesh`); капля не появляется и разбивается там, где `skyTop` выше неё.
  «Низкая» — без частиц; телефон — 45 %; ⚙️ «Сколько частиц».
- Поверхности (gfx.js, кусок `normal_fragment_maps`, только `STANDARD` и `LAMBERT` — человечки (toon/phong) не трогаются;
  только непрозрачное; `D37_NOCLIM` у материала — без погоды): мокрое — темнее и глаже (блестит, трассировка отражает лужи),
  лужи — на ровном по шуму в мировых координатах (рябь от капель), снег — на смотрящем вверх с шумным краем (растёт и тает),
  листва (`D37_LEAF`: R.wave / `wave: 'leaves'`, трава) — осенью желтеет и краснеет, зимой тусклее; хвоя (`needles`) — нет.
  Где «над головой» что-то есть (крыша, крона, потолок) — ни снега, ни мокрого: карта высот сверху 256² (рисуется раз в
  ~2 с и при уходе камеры, в остальных кадрах — 0 работы), у «Кубомира» — свет неба блока.
- Лёд: вода движка (`E.waterMaterial`, кусок под `D37_CLIM`) при `ice` > 0 — белёсая, матовая, с трещинами, без ряби, не прозрачная,
  сверху снег; ходить — игра спрашивает `X.iceAt(x, z)` / `W.at(…).ice` (от 0,8).
- Молния: вспышка (экспозиция на 0,15 с) + гром через 1–3 с (synth `wx_thunder`), только в сильную грозу, раз в 25–60 с.
- Радуга: после дождя днём, солнце за спиной — дуга на куполе (кусок купола, только наборы с небом v2 и «Обычные» на mid+).
- Всё новое в шейдерах — под define (`D37_CLIM`, `D37_LEAF`, `D37_RBOW`); страж графики (post.js, ключ `clim`): программа
  не собралась — без погоды на поверхностях (пересборка мира), кадр с погодой чернеет/«не числа» — без неё (сразу).
  «Обычные» — ровно прежний вид, кроме самой погоды.

## 7. Праздник и новогоднее задание (js/core/celebrate.js)

- `D37Celebrate.show(id | holiday, { big })`, `countdown(n)`, `fireworks(n, style)`, `confetti(n, style)`, `stop()` — холст
  поверх всего (z 99000: выше полного экрана игр, ниже окон сайта), без DOM-рамок; звук — свой маленький синтез (или
  `D37E.audio`). `prefers-reduced-motion` и «Экономный» режим — без вспышек, меньше частиц. ⚙️ «Праздники» выкл — ничего.
- Каждую секунду: местное время → фаза праздника. За 10 с до 00:00 1 января — цифры 10…1, в 00:00 — салют 3 минуты и
  «🎆 С Новым годом!». Открыл сайт в праздник — поздравление один раз (полоса на главной и коротко в мире).
- «🎄 Новогоднее задание» (1–31 декабря, до 00:00 1 января): карточка во всех мирах (`.cel-adv`, над HUD игры, на телефоне —
  компактная, свернуть — до значка с отсчётом; убрать нельзя) и полоса на главной сайта. Отсчёт до Нового года + задание
  дня (`ADVENT`, 31 штука: сыграть, зайти в мир, переодеть персонажа, позвать друга, написать в чат…). Выполнено — сайт
  видит сам (события `d37:game`, переходы `#/…`, `d37:chatmsg`); прогресс — `localStorage d37_advent`. Награда за сервер —
  потом (раздел 9). 1 января в 00:00 — карточка превращается в праздник и исчезает к 3 января.

## 8. Задел для персонажей как в Симс (после 21.10)

## 10. Подключение

### «Студия 3D» (сделано, js/games/studio3d-weather.js)
Панель «🌦 Погода»: времена года (выкл / как в общем мире / по игровым дням: N / один сезон), погода (авто / одна).
Хранится в мире: `SC.settings.weather = { mode, days, season, weather, climate, seed }` — сохраняется, выкладывается, гостям
— блоком world (как режим игры). Скрипты: `Weather.State`, `Weather.Temperature`, `Weather.FeelsLike`, `Weather.Season`,
`Weather.Wind`, `Weather.Today` (праздник или ''), события `Weather.Changed(state, season)`, `Weather.Holiday(id, greeting)`;
`Weather.Set(state)` — только у хозяина мира. JS, Lua, C#, Java.

### «Кубомир» (сделано)
kubomir-weather.js берёт сезон и погоду у движка (`W.at` с климатом по биому: пустыня, снега, горы, море…), свои частицы
под крышей остались. Зимой снег на верхних гранях (по свету неба блока — в пещерах и домах нет), осенью листва и трава
желтеют, озёра замерзают (картинка + по льду можно ходить, блоки мира не меняются), весной тает. ⚙️ «🧊 Кубомир» →
«Времена года»: как в общем мире (по умолчанию) / по игровым дням / выкл.

### «Мир Денчика» — ПРОВОДКА ДЛЯ АГЕНТА МИРА (mir*.js сейчас правит он; ~10 строк)
1. В список скриптов игры `world` (games.js) уже добавлены `js/engine/climate.js`, `js/engine/precip.js`.
2. После создания `R` и физики `ph` (mir.js, там где `R.clouds(...)`):
   ```js
   S.wx = D37E.climate.attach(R, {
     world: { seed: 'mir', mode: 'calendar', climateAt: (x, z) => mirClimate(x, z), seaY: 0, lapse: -.12 },
     where: () => [x, y, z своего персонажа],   // в координатах сцены
     skyTop: D37E.precip.physTop(ph, 400),          // крыши и навесы — из физики (у крыш есть тела, 15.10)
     water: (x, z) => ph.waterLevel ? ph.waterLevel(x, z) : -Infinity,   // пруд, фонтан, море карты
     hour: () => R.lighting.time, sound: AU,
   });
   ```
   `mirClimate`: детский городок, столица — `temperate`; взрослый город — `temperate`; боевая зона на побережье — `sea`;
   горы карты (worldmap.js: высота > 60) — `mountain`; степь/равнины — `steppe`; пустыня (если есть биом) — `desert`.
3. В кадре, до `R.render()`: `S.wx.frame(dt)` (сам attach в кадр не встраивается); при выходе из мира: `S.wx?.dispose()`.
4. Пруд и фонтан: `R.water(...)` уже знает лёд (кусок `D37_CLIM` у воды движка); ходить по льду — в `ph.waterLevel` вернуть
   `-Infinity` и включить коллайдер-пол на уровне воды, когда `S.wx.iceAt(x, z) >= .8`.
5. Листва: деревья и кусты через `R.prefab('tree'|'bush')` и `R.wave` желтеют сами; свои материалы листвы —
   `D37E.climate.leaf(material, 'leaves'|'grass'|'needles')` (до первого кадра).
6. Детский городок (0+): всё как везде, но `storm: false` в `world` (грозы там без грома — только дождь).
7. Время суток уже общее (`E.dayClock`) — погода у всех одна (зерно 'mir' + реальное время).
