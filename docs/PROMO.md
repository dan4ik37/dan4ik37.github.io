что сайт настоящий (без внешних ссылок поисковики показывают сайт очень неохотно). Копируй и вставляй.

## 1. YouTube — описание канала и «Ссылки»

**Куда:** YouTube Studio → Настройка канала → Основная информация.
В поле «Ссылки» → «Добавить ссылку»: название `Сайт dan4ik37`, адрес `https://dan4ik37.vercel.app`.

**Текст для описания (вставить в начало):**

```
🎮 Мой сайт: https://dan4ik37.vercel.app
Там — все 6000 видео по играм, чат, онлайн-игры с друзьями («5 букв», морской бой, города),
тесты «Какой ты моб из Майнкрафта?» и «Кто ты из FNAF?», колесо фортуны и генератор ников.
```

## 5. Twitch — панель под стримом

**Куда:** канал Twitch → «О себе» → «Изменить панели» → «+» → картинка `img/promo/twitch-panel.png` из папки сайта,
ссылка `https://dan4ik37.vercel.app`, описание: `Игры с чатом, тесты и все видео — на моём сайте`.

**Команда для бота в чате (если есть Nightbot/Moobot):** `!сайт` → `Сайт: https://dan4ik37.vercel.app — игры, тесты, чат 🎮`
