# Шейдеры 2D — наборы картинки для 2D-игр сайта

Модуль: `js/engine/shade2d.js` → `window.D37E.shade2d`. Первый пользователь — «Подземье» (`js/games/podzem-gl.js`,
`js/games/podzem.js`). Дальше его можно подключать к старому 2D-миру, «Орде», «Арене», 2D-играм «Студии игр».

## Наборы и настройка

Игрок выбирает в **⚙️ → Графика → «Шейдеры»** (в 2D-игре, которая отметилась `D37E.shade2d.use()`, вкладка «Графика»
показывает только этот выбор) или в меню самой игры. Ключ настройки — **`shaders`** (`D37Settings`), на живую —
`D37Opt.gfx.shaders`; полоски CRT — ключ **`crt`** (`D37Opt.gfx.crt`). Тот же ключ берут 3D-наборы движка.

| Набор | Что даёт | Цена |
|---|---|---|
| **Авто** (`auto`) | пресет графики «Ультра» → «Ультра», «Высокая» → «Красивые», «Низкая»/«Средняя» → «Обычные»; пресет «Авто»/«Своя» — по устройству (`E.quality()`: мощный компьютер — «Красивые», телефон — «Обычные») | — |
| **Обычные** (`normal`) | плавный цветной свет, мерцание огня, ореолы у огня, тень от блоков на стенах, волны и блик воды. Без постобработки. На слабом устройстве (`E.quality() === 'low'`) — `q = 0`, без мелочей | как раньше |
| **Красивые** (`pretty`) | + объём текстур и кромок по свету, лучи в воде, параллакс фона пещер, искры; постобработка: свечение (bloom), рябь воды и дрожь воздуха над лавой, цвет кадра по краю мира, виньетка | +4 прохода (свечение — в ¼ размера) |
| **Ультра** (`ultra`) | + свет ещё мягче (5 выборок), свечение шире (2 размытия), дымка вокруг огня, больше искр | +6 проходов |
| **Ретро** (`retro`) | свет клетками (как в старой Террарии), пиксели вдвое крупнее, меньше оттенков; по желанию — полоски CRT | дешевле «Обычных» (кадр в ½) |

Ключ общий с 3D: набор, которого в 2D нет (например, «Мультяшные» — `toon`), берётся как «Красивые»; незнакомое значение — как
«Авто». Новый 3D-набор — добавить его в `define('shaders', { list })` (gfx-settings.js) и, если нужно, в `ALIAS` (shade2d.js).

`flags()` — что включено сейчас: `{ id, name, q (0…3 — детали в своих шейдерах игры), smooth, post, bloom, bloomBlur,
distort, vignette, grade, pixel, posterize, crt, particles }`. Замер на компьютере (1098×600, видеокарта): кадр «Подземья»
0,10 мс («Обычные») / 0,14 («Красивые») / 0,15 («Ультра») / 0,03 («Ретро»).

## API

```js
const S2 = D37E.shade2d;
S2.pack();            // 'normal' | 'pretty' | 'ultra' | 'retro' — что действует сейчас
S2.flags();           // признаки набора (см. выше)
const off = S2.use(); // игра открыта и рисуется этими шейдерами → в ⚙️ появится «Графика → Шейдеры»; off() — закрыли
S2.on(fn);            // сменили набор → fn(pack) (проверять S2.poll() раз в кадр или читать flags() по D37Opt.rev)
S2.GLSL;              // куски шейдеров (GLSL ES 3.00): noise, light, aoWall, water — см. ниже
```

### Постобработка своего WebGL2-рисовальщика

```js
const P = S2.create(gl);          // P.ok = false — не собралась или рисует чёрным (проверка при создании) → рисуй как раньше
// каждый кадр:
if (P.begin(w, h, S2.flags())) { /* рисуем кадр — он идёт в буфер P (область P.sw × P.sh) */ }
else { /* постобработки нет: P сам привязал экран и viewport w × h */ }
P.field(data, fw, fh, [u0, v0, u1, v1]);   // по желанию: поле искажений (RGBA, R — вода: рябь, G — жар: дрожь воздуха),
                                           // и где оно на экране (uv левого верха и правого низа, y вниз)
P.end({ time, grade: { tint: [r, g, b], sat, con, bright }, bloom: 1, vignette: 1, threshold: .7 });
```

Проекция игры должна быть в долях экрана (как у «Подземья»: `uScale = 2 · клетка / ширина`) — тогда «Ретро» (кадр меньше
экрана) работает без правок. Своё `gl.viewport(0, 0, w, h)` после `begin()` не вызывать.

### Игры на Canvas 2D (заготовка)

```js
const O = S2.overlay(myCanvas, { parent });   // WebGL-холст поверх своего (pointer-events: none)
O.dark = .6;                                   // темнота вокруг (0 — нет)
O.light(x, y, r, [255, 180, 90], 1);           // свет-«пятно» на этот кадр (пиксели холста)
O.draw({ time, grade });                       // после того как игра нарисовала кадр
O.dispose();
```

Кадр Canvas 2D каждый раз уходит в текстуру (`texImage2D`) — на телефонах в 1080p это заметно; подключать начиная с игр с
небольшим холстом.

## Куски GLSL (`S2.GLSL`)

- `noise` — `s2hash(ivec2)`, `s2noise(vec2)` (гладкий шум 0…1), `s2lum(vec3)`. Отрицательные координаты — сдвигом в плюс
  (перевод отрицательного int в uint на части видеокарт не определён).
- `light` — `s2light(block, sky, skyCol, pw, t, q)`: свет клетки → яркость (кривая 0,75 и пересвет у огня, мерцание огня при
  `q ≥ 1`), небо — что ярче. Свет клеток — 8 бит на канал, распространение — `relight()` в `js/games/podzem-core.js`
  (доля за клетку: воздух 0,89, твёрдое 0,56, вода по цветам, лава 0,7).
- `aoWall` — `s2ao(mask8, f)`: тень от твёрдых соседей на стене за ними.
- `water` — `s2wave(pw, t, lava)`, `s2rays(pw, t)`, `s2lava(pw, t)`.

## Телефоны — обязательно

- Все сэмплеры — `precision highp sampler2D` / `usampler2D` (иначе телефон читает текстуру в fp16 — «пятна»).
- `smoothstep(a, b, x)` — только `a < b` (иначе не определено; на части телефонов — чёрное).
- Без расширений WebGL; `layout(location = 0)` у вершин.
- Проверка после сборки: `P.ok` (серый кадр через сборку должен остаться серым), у «Подземья» — ещё `R.selfTest()` шейдеров
  клеток и неба (кусок стены и неба → пиксель не чёрный); не прошло — простые шейдеры 1-й версии.
- Тест: `node scripts/tiles-test.cjs shade2d` — наборы, «Авто», highp у всех сэмплеров, smoothstep с числами — по возрастанию.
