# Приложение dan4ik37 на ПК и телефонах — и в магазинах

Владелец 15.10.2026: «сделать их полноценными приложениями на ПК и другие устройства, чтобы не держать в браузере… но реклама же будет?»

**Коротко:** сайт теперь ставится как настоящая программа (PWA) — на Windows, Mac, Linux, Android, iPhone и iPad, без
магазинов и бесплатно. Своё окно без вкладок, значок на рабочем столе и экране телефона, ярлыки, счётчик сообщений на значке,
уведомления, «Поделиться» в чат, игры без интернета, обновления сами. **Реклама работает как на сайте** — потому что
установленный PWA — это тот же сайт, просто в своём окне браузера. Программу «как Discord» (Electron) делать НЕ стали:
в программах реклама AdSense запрещена.

Магазины (Google Play, RuStore, Microsoft Store) — по желанию: файлы подготовлены, аккаунты заводит владелец (шаги ниже).

## 1. Как люди ставят приложение (уже работает, ничего делать не надо)

| Где | Как | Что получится |

| iPhone / iPad (Safari) | «Поделиться» → «На экран «Домой»» (в iOS 26 — «•••» → «Поделиться») — на сайте инструкция с картинками | значок на экране «Домой», своё окно; уведомления — iOS 16.4+ |
| Компьютер: Chrome, Edge, Яндекс Браузер | та же кнопка (браузер спросит «Установить?») или значок установки в строке адреса | программа в меню «Пуск» / Launchpad, на панели задач, своё окно |

**Ссылка для соцсетей:** `https://dan4ik37.vercel.app/#/app` — сразу открывает окно «Как установить» (для постов «Скачай приложение»).

Что умеет установленное приложение:
- своё окно без вкладок и строки адреса; на ПК шапка сайта становится заголовком окна (можно включить стрелкой «⌃» вверху окна);
- ярлыки по правому клику на значке (на телефоне — долгим нажатием): **Мир, Чат, Игры, Слово дня, Магазин**;
- число на значке: непрочитанные личные сообщения + пропущенные звонки + новые уведомления 🔔 (выключается в ⚙️ Настройки → Сайт);
- «Поделиться» из других приложений (ролик с YouTube, ссылка) → «В общий чат» или «Другу в личку» (сообщение само не уходит);
- без интернета открывается сам и играются судоку, пасьянсы, 2048, блоки, сапёр, маджонг, змейка, шахматы, шашки и др.;
- обновляется само; когда выходит новая версия сервис-воркера — полоска «✨ Доступна новая версия — Обновить».

Статистика установок (без личных данных — только ОС и браузер):
- **Метрика:** создай цель «JavaScript-событие» с идентификатором `app_installed` — будет число установок.
- **Vercel Analytics:** события `app_install_click`, `app_installed`, `app_open`, `app_card_show`, `app_guide_open`, `app_update`
  (свои события Vercel показывает не на всех тарифах; если их не видно — смотри Метрику).

## 2. Реклама: где какая работает

| Где открыт сайт | AdSense | РСЯ (Яндекс) | Своя реклама (кабинет рекламодателя) |
|---|---|---|---|
| Сайт в браузере | ✅ | ✅ | ✅ |
| **Установленный PWA** (Chrome, Edge, Яндекс, Safari «На экран Домой») | ✅ — это веб-страница в браузере | ✅ — так же | ✅ |
| **Google Play / RuStore — TWA** (Android-приложение показывает сайт через Chrome) | ✅ — в правилах AdSense Trusted Web Activities прямо названы среди разрешённых способов показа сайта в приложении [1] | ❓ **уточнить в поддержке РСЯ** — про приложения у РСЯ отдельные правила, про показ сайта в приложении правил нет [2] | ✅ |
| TWA на телефоне без Chrome (запасной вариант) | ✅ если запасной вариант — Custom Tabs (так и настроено); ❌ если WebView без «WebView API for Ads» [1] | ❓ | ✅ |
| Microsoft Store (PWA в пакете MSIX — сайт в Edge) | ❓ **уточнить**: это тот же сайт в Edge, но распространяется как программа из магазина, а AdSense запрещает свой код «в программах (software)» [1] | ❓ | ✅ |
| Программа для ПК со своим браузером внутри (Electron, Tauri) | ❌ «AdSense code may not be placed in … software» [1] | ❌ / ❓ | ✅ |
| Настоящее мобильное приложение (код Android/iOS) | — вместо AdSense нужен AdMob (Google Mobile Ads SDK) | — вместо РСЯ нужен Yandex Mobile Ads SDK | ✅ |

Источники:
1. Правила программы AdSense — https://support.google.com/adsense/answer/48182 (то же: https://support.google.com/publisherpolicies/answer/48182):
   «AdSense code may not be placed in inappropriate places such as pop-ups, emails or software»; раздел «Technical requirements
   for web content viewing frames for apps» — для Android разрешены Chrome Custom Tabs и Trusted Web Activities, WebView — только
   через WebView API for Ads (Google Mobile Ads SDK).
2. Правила РСЯ — https://yandex.ru/support/partner/ru/yan-rules/ (мобильные приложения проходят свою модерацию; про сайт внутри
   приложения отдельного правила нет — спросить поддержку партнёров).

Сборки для магазинов помечают себя (`?app=play`, `?app=rustore`, `?app=ms`, на Android — ещё и по пакету): сайту видно
`D37App.source()`. Если поддержка РСЯ или Google скажет «в этом магазине нельзя» — в этой сборке можно оставить только свою
рекламу, не трогая сайт.

## 3. Google Play (Android) — Trusted Web Activity

**Что это:** маленькое Android-приложение, которое открывает сайт в Chrome на весь экран, без строки адреса. Сайт внутри —
тот же, обновлять приложение в магазине нужно только при смене значка/названия.

**Прежде чем начать — важно:**
- Аккаунт разработчика Google Play — **25 $ один раз**, нужна карта, которая платит за границу (российские Google не принимает),
  и подтверждение личности.
- Новый личный аккаунт: перед выпуском — **закрытое тестирование: не меньше 12 тестировщиков 14 дней подряд**
  (https://support.google.com/googleplay/android-developer/answer/14151465). Позови зрителей стрима — им нужен Gmail.
- **Покупки:** по правилам Google Play цифровые товары (кристаллы, VIP за донат) внутри приложения из Play продаются только
  через Google Play Billing (https://support.google.com/googleplay/android-developer/answer/9858738). Поэтому в сборке для Play
  (`?app=play`) магазин, донат и VIP **спрятаны** (html.app-play). Перед публикацией пройди приложение и проверь, что ссылок на
  покупки не осталось (в играх, в профиле). Реклама — можно.

**Шаги (без программирования, через PWABuilder):**
1. Открой https://www.pwabuilder.com, вставь `https://dan4ik37.vercel.app` → «Start».
2. «Package For Stores» → **Android** → «Generate Package». В «Options»:
   - Package ID: `app.vercel.dan4ik37.twa`
   - App name: `dan4ik37 — игры, чат и видео`, Launcher name: `dan4ik37`
   - Start URL: `/?app=play`
   - Signing key: «Create new» (имя, организация — любые)
   - Fallback behavior: **Custom Tabs** (не WebView — иначе AdSense нельзя)
   - Notification delegation: включено
3. Скачай архив. В нём `.aab` (для Play), `.apk` (поставить себе для проверки), `signing.keystore` и `signing-key-info.txt`.
   **Ключ и пароль сохрани в надёжном месте (не в репозиторий, он открытый!)** — без них приложение не обновить.
4. Отпечаток ключа → в `.well-known/assetlinks.json` (без этого вверху приложения будет строка адреса):
   в `signing-key-info.txt` строка `SHA-256 fingerprint` (вида `AB:CD:…`, 32 пары) — вставь её вместо `ЗАМЕНИТЬ-2`
   (или просто пришли её агенту — впишет он). Отправь в main → через минуту проверь, что открывается
   https://dan4ik37.vercel.app/.well-known/assetlinks.json
5. Play Console (https://play.google.com/console) → «Создать приложение» → «Тестирование» → «Закрытое тестирование» →
   загрузи `.aab`. Включится «Подпись приложений в Google Play»: на странице **Целостность приложения → Подпись приложений**
   скопируй «SHA-256 сертификата ключа подписи приложения» и вставь вместо `ЗАМЕНИТЬ-1` в `assetlinks.json` (у Play свой ключ —
   нужны оба отпечатка).
6. Проверка: https://developers.google.com/digital-asset-links/tools/generator — домен `dan4ik37.vercel.app`, пакет
   `app.vercel.dan4ik37.twa`, отпечаток → «Test statement» → зелёная галочка.
7. Карточка магазина: иконка 512×512 — `img/app/maskable-512.png`; скриншоты — `img/app/shot-narrow-*.webp` (перевести в PNG,
   например в Paint «Сохранить как»); возрастной рейтинг — анкета IARC (чат с незнакомыми, покупок в этой сборке нет);
   политика конфиденциальности — `https://dan4ik37.vercel.app/privacy`.
8. 14 дней теста → «Подать заявку на доступ к рабочей версии» → публикация.

Готовый конфиг для Bubblewrap (командная строка вместо PWABuilder, если захочет программист): `apps/android/play/twa-manifest.json`
(`npm i -g @bubblewrap/cli`, потом в этой папке `bubblewrap build`; нужен JDK 17 и Android SDK — Bubblewrap скачает сам).

## 4. RuStore (Android, Россия)

Аккаунт разработчика RuStore — бесплатно (https://console.rustore.ru). Правила модерации:
https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps — что важно для нас:
- **§8.2:** нельзя «публиковать мобильный сайт в виде самостоятельного приложения без дополнительной функциональности»;
  WebView-приложения — только с дополнительной функциональностью и «должны восприниматься как самостоятельное мобильное
  приложение». Наш довод: своё окно без браузера, офлайн-игры, push-уведомления, счётчик на значке, ярлыки, «Поделиться»,
  свой 3D-мир, звонки. Риск отказа всё равно есть — в описании так и перечисли.
- **§9.1:** все способы оплаты нужно задекларировать (кристаллы — TipTop Pay / Freedom Pay / Kaspi, VIP — донат через
  DonationAlerts). Незадекларированные — запрещены.
- **§9.5:** реклама вне приложения (на экране блокировки, в уведомлениях) запрещена — наши уведомления только о видео и стримах.
- **§3.1:** возрастной рейтинг — по ФЗ-436 (на сайте метка **12+**: чат и мир с незнакомыми).

Шаги: как в Google Play (PWABuilder), но Package ID `app.vercel.dan4ik37.rustore`, Start URL `/?app=rustore`, ключ — свой
(отдельный от Play), в RuStore загружается `.apk` (или `.aab`, если консоль примет). Отпечаток ключа — вместо `ЗАМЕНИТЬ-3`
в `.well-known/assetlinks.json`. Магазин кристаллов в этой сборке виден (задекларируй оплату). Конфиг для Bubblewrap —
`apps/android/rustore/twa-manifest.json`.

## 5. Microsoft Store (Windows) — PWABuilder, пакет MSIX

Регистрация разработчика-физлица с сентября 2025 — **бесплатно** (https://storedeveloper.microsoft.com, учётная запись Microsoft
+ подтверждение личности). Шаги:
1. Partner Center → «Приложения и игры» → «Новый продукт» → «Приложение MSIX или PWA» → зарезервируй имя `dan4ik37`.
2. «Удостоверение продукта» (Product identity): скопируй **Package/Identity/Name**, **Package/Identity/Publisher** (CN=…) и
   **Package/Properties/PublisherDisplayName**.
3. https://www.pwabuilder.com → `https://dan4ik37.vercel.app` → «Package For Stores» → **Windows** → «Generate Package» →
   вставь три значения из шага 2, версия `1.0.0`, Start URL `/?app=ms`.
4. Скачай архив → в Partner Center → «Отправка» → «Пакеты» загрузи `.msixbundle` (и `.classic.appxbundle`, если он есть).
5. Карточка: снимки — `img/app/shot-wide-*.webp` (в PNG), возраст — анкета IARC, политика — `/privacy`.
6. Реклама в версии из Microsoft Store — см. таблицу выше («уточнить»); своя реклама работает в любом случае.

## 6. iPhone / iPad — почему не App Store

- Правило Apple **4.2 «Минимальная функциональность»**: «Your app should include features, content, and UI that elevate it
  beyond a repackaged website» — сайт в обёртке Apple обычно отклоняет (https://developer.apple.com/app-store/review/guidelines/).
- Аккаунт Apple Developer — **99 $ в год**, из России оплатить сложно; собирать можно только на Mac с Xcode.
- Поэтому на iPhone путь — **«На экран «Домой»»**: своё окно, значок, push-уведомления (iOS 16.4+), счётчик на значке. На сайте
  для этого есть инструкция с картинками (меню → «📲 Установить приложение» или ссылка `/#/app`).

## 7. Что проверить на проде в обычном Chrome (встроенный браузер Claude не умеет service worker)

1. https://dan4ik37.vercel.app → меню «Ещё» → «📲 Установить приложение» → «Установить» → открылось окно без вкладок.
2. В окне: стрелка «⌃» вверху (свернуть заголовок) → шапка сайта стала заголовком окна, кнопки окна не закрывают меню,
   окно тянется мышью за пустое место шапки.
3. Правый клик по значку на панели задач → ярлыки Мир / Чат / Игры / Слово дня / Магазин → открываются в том же окне.
4. Войти, попросить друга написать в личку → на значке приложения появилось число; прочитать → число пропало.
5. DevTools (F12) → Application → Service Workers: `sw.js` активен; Cache Storage: `d37-shell-v3`, `d37-rt-v1`, в них нет `/api/`,
   рекламы, Supabase. Network → Offline → обновить: открылась главная из кэша; `#/games/sudoku` играется; `/videos` →
   «Нет интернета».
6. Android: поделиться ссылкой из YouTube → «dan4ik37» в списке → окошко «В общий чат / Другу».
7. iPhone: Safari → «На экран «Домой»» → открыть с значка → 🔔 в профиле → пришло приветствие.
8. Ссылка `web+denchik://c/<код>` (на ПК после установки браузер спросит, открывать ли такие ссылки в приложении).
9. После выпуска новой версии `sw.js` (поднят `VERSION`): в открытом окне через минуту — «✨ Доступна новая версия» → «Обновить».

Автоматически (до выкладки): `node scripts/pwa-test.cjs` — логика в node; `node scripts/pwa-e2e.cjs` — настоящий Chrome
(старый sw.js → новый, без сети главная и судоку работают, «Обновить» ставит новую версию).

## 8. Для разработчиков (агентов)

- `js/features/app.js` (D37App): установка, карточка, окно приложения, WCO, «Назад» на Android, значок, «Поделиться», web+denchik,
  launchQueue, обновления sw.js, файлы игр без интернета (OFFLINE_GAMES — как в `offline.html`), сборка для Play (html.app-play).
- `js/features/app-guide.js` — окно «Как установить» (шаги и SVG-картинки); поменял — подними `VER` в app.js.
- `sw.js` — поменял — подними `VERSION`. Никогда не кэширует `/api/*`, `/go/*`, Supabase, рекламу, Метрику.
- `manifest.json`, значки — `python -X utf8 scripts/make-app-icons.py`, снимки — `node scripts/app-shots.cjs http://localhost:5555`.
- Магазины: `.well-known/assetlinks.json` (отпечатки ключей), `apps/android/{play,rustore}/twa-manifest.json`. Ключи подписи и
  готовые `.apk/.aab/.msix` в репозиторий не кладём (`.gitignore`).
- Схема `web+dan4ik37` по правилам HTML невозможна (после `web+` — только латинские буквы), поэтому `web+denchik`.
