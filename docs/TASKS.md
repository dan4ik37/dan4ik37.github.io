## 🙋 Ждёт владельца
- Vercel Hobby — только для некоммерческих сайтов; реклама и платежи по их правилам — коммерция (риск приостановки). Решить: Vercel Pro (~20 $/мес) или переезд на хостинг, где это бесплатно разрешено.
- Резервные копии: один раз настроить по docs/BACKUPS.md (пароль базы вводит только владелец).
- РСЯ: повторная модерация (Реклама на сайтах → Сайты) — можно с 17.10.
- Google Search Console: «Запросить индексирование» (список — CLAUDE.md «Отложено», п. 2); после T-007 — новые адреса.
- Оплата: ИП/самозанятость и Kaspi Pay для бизнеса → ссылка KASPI_PAY_LINK в Vercel (вводит только владелец).
- Ссылки на сайт в описаниях YouTube, Twitch, ВК, Telegram (docs/PROMO.md).
