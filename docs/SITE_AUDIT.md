## Ограничения, о которых помнить
- **Квота YouTube API 10 000/сутки.** Полный архив (~120 запросов) берут только `/sitemap.xml` и `/videos`
  (их ответы кэширует CDN). Страница ролика — `getUploads(200)`: краулеры открывают тысячи `/v/<id>`.
- Главная — SPA на `#/…`: поисковик видит почти только `index.html`. Всё, что должно искаться, — серверные страницы.
- Google в РФ рекламу не показывает — для российских зрителей нужна РСЯ (`ADS_IDS.yandex`).
