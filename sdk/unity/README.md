# SDK Денчика для Unity

Сделал игру в Unity? Подключи этот SDK, собери игру для браузера (WebGL), выложи её в интернет и добавь ссылку
на сайте **dan4ik37.vercel.app** («Игры» → «Unity-игры» → «➕ Добавить свою игру»). Тогда:

- в игре известен **ник игрока** с сайта (гость он или вошёл, VIP ли он, картинка его персонажа);
- **очки и итог раунда** идут в рекорды твоей игры, за победы игрок получает **XP сайта**, за раунд — **монеты 🪙**;
- друзья играют вместе в **комнате по ссылке**: кто зашёл первым — тот **хост**, его игра ведёт партию,
  остальные подхватывают. Ушёл хост — хостом становится следующий;
- игроки соединяются напрямую (быстро), а если не вышло — через сервер сайта. Сервер для игр тебе не нужен.

Без сайта всё тоже работает: в редакторе Unity игрок — «Игрок», очки пишутся в консоль, комнаты — понарошку
(можно «добавить друга» и проверить, как игра ведёт себя на хосте и на госте).

---

## Что нужно

1. **Unity 2021.3 или новее.**
2. **Модуль WebGL.** Unity Hub → *Installs* → ⚙ у своей версии Unity → *Add modules* → **WebGL Build Support**.
3. **Аккаунт на сайте** dan4ik37.vercel.app — чтобы сохранить игру и дать ссылку друзьям.
4. **Место в интернете для файлов игры** (бесплатно): GitHub Pages, itch.io или любой свой сайт с адресом `https://`.
   Сам сайт Денчика файлы игр не хранит — только ссылку на них.

### Что такое WebGL — простыми словами

Обычно Unity собирает игру в программу для Windows (`.exe`). **WebGL** — это сборка для браузера: вместо `.exe`
получается папка с `index.html` и папкой `Build`. Если положить эту папку в интернет, игра открывается по ссылке
в Chrome, Яндекс Браузере, на телефоне — без установки. Сайт Денчика показывает такую страницу у себя в окошке.

## Шаг 1. Подключить SDK

**Проще всего:** на сайте «Unity-игры» → «📘 Как сделать игру» → **«📦 Скачать SDK (zip)»**. Распакуй архив и
перетащи папку `D37SDK` в окно *Project* Unity (в `Assets`).

Или возьми папку [`sdk/unity` на GitHub](https://github.com/dan4ik37/dan4ik37.github.io/tree/main/sdk/unity)
и скопируй её в `Assets/D37SDK`. Или через Package Manager: *Window → Package Manager → + → Add package from disk…* →
выбери `package.json` в папке SDK.

Что внутри:

```
D37SDK/
  Runtime/D37.cs              — всё, что зовёт твоя игра: D37.Init, D37.Score, D37.Over, D37.Room…
  Runtime/D37Bridge.cs        — приёмник сообщений сайта (создаётся сам, в сцену класть не нужно)
  Plugins/WebGL/D37Bridge.jslib — связь с сайтом в браузере (работает сама)
  Editor/D37Setup.cs          — меню «SDK Денчика» (настроить сборку одним нажатием)
  Samples/D37Example.cs       — пример: кнопки, очки, комната с хостом
  WebGLTemplates/D37/         — страница игры: на всё окно, полоса загрузки по-русски
```

Обновить SDK — просто заменить папку целиком.

## Шаг 2. Пара строк в коде

```csharp
using UnityEngine;

public class MyGame : MonoBehaviour
{
    int score;

    void Start()
    {
        D37.Init(() => Debug.Log("Играет " + D37.Player.Nick));   // подключиться к сайту
        D37.OnResult += r => { if (r.Ok) Debug.Log("+" + r.Xp + " XP, +" + r.Coins + " монет"); };
    }

    void AddPoint()
    {
        score++;
        D37.Score(score);        // счёт по ходу игры — сайт показывает его под игрой
    }

    void PickCoin()
    {
        D37.AddCoins(1);         // монеты сайта за этот раунд (всего до 50)
    }

    void GameOver(bool win)
    {
        D37.Over(score, win);    // конец раунда: рекорд, XP за победу, монеты
        score = 0;
    }
}
```

| Что | Как |
|---|---|
| Подключиться | `D37.Init(() => { … })` — один раз, например в `Start` первой сцены |
| Кто играет | `D37.Player.Nick`, `.Id` (постоянный номер игрока в твоей игре), `.IsGuest`, `.IsVip`, `.LoadAvatar()` |
| Игра на сайте? | `D37.IsOnline` (false — в редакторе или если сборку открыли отдельно) |
| Счёт по ходу | `D37.Score(очки)` — можно звать хоть каждый кадр |
| Монеты за раунд | `D37.AddCoins(n)` — копятся до `D37.Over`, всего до 50 |
| Конец раунда | `D37.Over(очки, победа)`, `D37.Win(очки)`, `D37.Lose(очки)` → ответ в `D37.OnResult` |
| Надпись на сайте | `D37.Toast("Новый уровень!")` |
| Сменился игрок (вошёл на сайте) | `D37.OnPlayerChanged` |

Очки — «больше — лучше». Если в игре важно время (меньше — лучше), отправляй, например, `100000 - миллисекунды`.

## Шаг 3. Комнаты — игра с друзьями (если нужна)

Игрок жмёт «👥 Создать комнату и позвать» под игрой на сайте **или** игра сама зовёт `D37.Room.Create()`.
Сайт показывает ссылку — друг открывает её и попадает в ту же комнату.

**Кто хост.** Хост — тот, кто зашёл в комнату первым. Его игра «главная»: считает мир, решает, кто победил,
проверяет ходы гостей и рассылает всем состояние. Гости шлют хосту свои действия и показывают то, что он прислал.
Так игрокам не нужен отдельный сервер. Ушёл хост — хостом становится тот, кто зашёл следующим: игра узнаёт это из
`D37.Room.OnHostChanged` и продолжает партию со своего последнего состояния.

```csharp
void Start()
{
    D37.Init();
    D37.Room.OnPlayerJoined += p => { if (D37.Room.IsHost) D37.Room.SendTo(p.Id, "state", JsonUtility.ToJson(world)); };
    D37.Room.OnHostChanged += host => { if (D37.Room.IsHost) D37.Room.Send("state", JsonUtility.ToJson(world)); };
    D37.Room.OnMessage += m =>
    {
        if (m.Type == "move" && D37.Room.IsHost) { ApplyMove(m.From, m.Data); D37.Room.Send("state", JsonUtility.ToJson(world)); }
        if (m.Type == "state" && m.From == D37.Room.HostId) world = JsonUtility.FromJson<World>(m.Data);
    };
}

void OnPlayerInput(string moveJson)
{
    if (D37.Room.IsHost) ApplyMove(D37.Room.MyId, moveJson);
    else D37.Room.SendToHost("move", moveJson);
}
```

| Что | Как |
|---|---|
| Создать / войти / выйти | `D37.Room.Create()`, `D37.Room.Join("код")`, `D37.Room.Leave()` |
| Где я | `D37.Room.InRoom`, `.Code`, `.Link` (ссылка для друзей), `.Max` |
| Кто хост | `D37.Room.IsHost`, `.HostId`, `.Host` |
| Кто в комнате | `D37.Room.Players` (у каждого `Id`, `UserId`, `Nick`, `IsHost`, `IsMe`), `D37.Room.MyId`, `D37.Room.GetPlayer(id)` |
| Сообщение всем | `D37.Room.Send("тип", json)` |
| Одному / хосту | `D37.Room.SendTo(id, "тип", json)`, `D37.Room.SendToHost("тип", json)` |
| Можно потерять | последний параметр `reliable: false` — для позиций, которые шлёшь часто |
| События | `OnJoined`, `OnLeft`, `OnPlayerJoined`, `OnPlayerLeft`, `OnHostChanged`, `OnMessage`, `OnError` |

**Ограничения:** сообщение — строка до 8192 знаков, тип — до 32 латинских букв/цифр (и `_ . : -`), от игры — до 30
сообщений в секунду. Сайт старается соединить игроков **напрямую** (WebRTC) — тогда быстро. Если напрямую не вышло
(бывает у мобильного интернета), сообщения идут через сервер — **не чаще 5 в секунду**, лишние отбрасываются
(`OnError("rate")`). Поэтому не шли позицию каждый кадр: 5–10 раз в секунду и плавное движение между ними — норма.
Игроков в комнате — от 2 до 8 (сколько — выбираешь, когда добавляешь игру на сайт).

**Проверка без сайта.** В редакторе: `D37.Room.Create()` создаёт комнату понарошку,
`D37.Simulate.AddPlayer("Друг")` — «друг» входит (с `true` — входит раньше тебя, то есть он хост, а ты гость),
`D37.Simulate.Receive(id, "move", json)` — «друг» прислал сообщение, `D37.Simulate.RemovePlayer(id)` — ушёл,
`D37.Simulate.OnSent` — что отправила твоя игра. Всё это — на кнопках в `Samples/D37Example.cs`.

## Шаг 4. Собрать игру для браузера (WebGL)

1. Меню **SDK Денчика → Переключиться на WebGL** (или *File → Build Settings → WebGL → Switch Platform*;
   в Unity 6 — *File → Build Profiles*).
2. Меню **SDK Денчика → Настроить сборку для сайта** — оно само выставит всё, что ниже.
3. *File → Build Settings → **Build*** → выбери пустую папку (например, `MyGame-Web`).
   Получится `index.html` и папка `Build` — это и есть игра для браузера.

Что настраивает меню (если делаешь руками — *Edit → Project Settings → Player → вкладка WebGL*):

| Настройка | Где | Значение |
|---|---|---|
| Compression Format | Publishing Settings | **Gzip** |
| Decompression Fallback | Publishing Settings | **✓ включено** |
| WebGL Template | Resolution and Presentation | **D37** (игра на всё окно) |
| Enable Exceptions | Publishing Settings | Explicitly Thrown Exceptions Only |
| Multithreading / Threads Support | Publishing Settings | **выключено** — на сайте не работает |

### Сжатие: Brotli или Gzip?

Unity сжимает файлы игры, чтобы они быстрее качались. Браузер сам распакует их, только если хостинг при отдаче
говорит, чем файл сжат (заголовок `Content-Encoding`). **GitHub Pages так не умеет**, многие другие хостинги тоже.
Галочка **Decompression Fallback** кладёт в игру свой распаковщик — тогда игра запускается на любом хостинге
(файлы будут называться `….unityweb`, старт чуть медленнее).

| Где лежит игра | Compression Format | Decompression Fallback |
|---|---|---|
| GitHub Pages | Gzip | ✓ включить |
| itch.io | Gzip | ✓ включить (так надёжнее) |
| Свой сервер, где можно настроить `Content-Encoding` | Brotli (файлы меньше, нужен https) | можно выключить |
| Не знаю | **Gzip** | **✓ включить** |

*Disabled* (без сжатия) тоже работает везде, но файлы самые большие — игра дольше грузится.

## Шаг 5. Выложить игру в интернет

### GitHub Pages (бесплатно)

1. Зарегистрируйся на [github.com](https://github.com).
2. *New repository* → имя, например `my-game` → **Public** → *Create repository*.
3. *uploading an existing file* → перетащи **содержимое** папки сборки (`index.html` и папку `Build`) → *Commit changes*.
   Через сайт GitHub можно загрузить файл до 25 МБ; если файл в `Build` больше — загрузи через программу
   [GitHub Desktop](https://desktop.github.com) (до 100 МБ на файл).
4. *Settings → Pages → Branch: **main**, папка **/ (root)** → Save*. Через минуту-две игра откроется по адресу
   `https://ТВОЙ-НИК.github.io/my-game/`.
5. Ссылка для сайта Денчика: `https://ТВОЙ-НИК.github.io/my-game/index.html`.

### itch.io

1. *Upload new project* → *Kind of project: **HTML*** → загрузи zip-архив папки сборки (`index.html` — в корне архива) →
   отметь *This file will be played in the browser* → страница — *Public* → *Save*.
2. Открой страницу игры, запусти её, нажми правой кнопкой по игре → «Открыть фрейм в новой вкладке» (или «Просмотреть
   код фрейма»). Адрес вида `https://html-classic.itch.zone/html/1234567/index.html` — это и есть ссылка для сайта.
3. Если на сайте Денчика игра с itch.io не открывается — выложи её на GitHub Pages.

### Свой сайт, Netlify, Vercel, Яндекс Облако…

Подойдёт любой хостинг статических сайтов с адресом `https://`. Загрузи папку сборки и возьми ссылку на `index.html`.

**Не подойдут:** Google Диск, Яндекс Диск, Dropbox (это хранилища файлов, а не сайты) и ссылки `http://` без «s».

## Шаг 6. Добавить игру на сайт

1. dan4ik37.vercel.app → «Игры» → **«Unity-игры»** → **«➕ Добавить свою игру из Unity»** (нужно войти в аккаунт).
2. Название, значок, описание, **ссылка на index.html**, форма окна (широкий экран, квадрат, телефон…), сколько игроков.
3. **«▶ Проверить»** — игра откроется прямо в форме. Под ней должно появиться **«✅ SDK»**: значит, сайт и игра
   друг друга слышат (ник, очки, комнаты работают). «⚠️ SDK не ответил» — см. «Если не работает».
4. **«💾 Сохранить»**, потом **«🔗 Ссылка для друзей»** — играть можно сразу всем, у кого есть ссылка.
5. **«🌍 В каталог»** — игру проверит модератор, после этого она появится в каталоге «Unity-игры».

## Правила и лимиты

- Без оскорблений, взрослого контента, азартных игр, просьб ввести пароль или личные данные. В каталог — после
  проверки модератором. 3 жалобы — игра уходит из каталога до новой проверки. Изменил игру из каталога — снова проверка.
- Сборка лежит у тебя: если поменяешь её после проверки так, что она нарушает правила, игру заблокируют.
- Итог раунда засчитывается **не чаще раза в 10 секунд**. За победу — **10 XP** (в общем дневном лимите игр сайта),
  монеты раунда — **до 50** (в общем дневном лимите сайта, не чаще раза в 20 секунд), у VIP — вдвое.
  **За свою игру автор наград не получает** (только рекорд — чтобы проверить таблицу).
- За каждые 10 запусков твоей игры другими игроками — **1 🪙 тебе** (до 100 в день).
- Игра открыта в «песочнице»: она не видит сайт и аккаунт игрока, не может открыть новое окно или вкладку
  (`Application.OpenURL` не сработает), показать `alert` или увести страницу сайта.

## Если не работает

- **Игра не грузится, в консоли браузера (F12) «Unable to parse Build/…gz» или «…br»** — включи
  *Decompression Fallback* и собери заново (или выбери Gzip).
- **«⚠️ SDK не ответил»** — в игре не вызывается `D37.Init()`; или ссылка ведёт не прямо на сборку (например, на страницу
  itch.io, а не на её `index.html`); или игра открылась с другого адреса (переадресация) — сайт подскажет, с какого.
- **Чёрный экран / не помещается** — выбери шаблон *D37* (Player Settings → Resolution and Presentation) или форму
  окна «Во всё окно» на сайте.
- **Нет звука** — браузер включает звук после первого нажатия в игре. Так задумано браузерами.
- **Сохранения (`PlayerPrefs`)** работают, но хранятся в браузере игрока отдельно для сайта Денчика.
- **Хост «завис»** — браузер усыпляет игру во вкладке, которую не видно. Хосту лучше держать вкладку с игрой открытой.
- **Не включай Multithreading** (потоки WebGL) — на сайте игра с ними не запустится.

## Для программистов: протокол

Игра работает в iframe (`sandbox="allow-scripts allow-same-origin allow-pointer-lock"`, сборка — на другом сайте).
Сообщения — `window.postMessage` объектами `{ d37u: 1, t: "<тип>", … }`. jslib шлёт только родительскому окну и только
на адрес сайта (`https://dan4ik37.vercel.app`, `https://dan4ik37.github.io`, для проверки — `http://localhost:*`),
принимает только от него, а после `init` — только с адреса, приславшего `init`. Сайт принимает только от своего iframe
и только с адреса зарегистрированной сборки; поля — по белому списку, длины и частота ограничены.

| Игра → сайт | Поля | Лимит |
|---|---|---|
| `hello` | `sdk`, `unity` | 2 подряд, потом 1 в 2 с |
| `score` | `n` (0…10⁹) | 10/с |
| `over` | `n`, `win`, `coins` (0…50) | 1 в 3 с (сервер — 1 в 10 с) |
| `toast` | `text` (до 140) | 1/с |
| `log` | `text` (до 300) | 5/с |
| `room.create` / `room.leave` | — | 1 в 2 с |
| `room.join` | `code` (`[a-z0-9]{4,12}`) | 1 в 2 с |
| `room.send` | `to` (пусто — всем), `type`, `data` (строка до 8192), `rel` | 30/с; через сервер — 5/с |

| Сайт → игра | Поля |
|---|---|
| `init` | `v`, `online`, `preview`, `player {id, nick, guest, vip, avatar}`, `game {id, title, players}` |
| `player` | `player` — игрок вошёл/вышел на сайте |
| `room.state` | `code`, `max`, `me`, `host`, `link`, `players [{id, uid, nick, guest, host, me}]` (пустой `code` — не в комнате) |
| `room.msg` | `from`, `type`, `data` |
| `room.error` | `reason`: `full`, `dup`, `offline`, `code`, `single`, `rate`, `nobody`, `no_room` |
| `result` | `ok`, `xp`, `coins`, `record`, `best`, `reason` |

Без Unity протокол можно проверить страницей `TestPage/index.html` (притворяется игрой с SDK).
