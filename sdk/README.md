# Скрипты на C++ и Rust для «Студии 3D»

В «Студии 3D» (dan4ik37.vercel.app → Игры → Студия 3D) скрипт можно писать не только на JavaScript, но и на **C++**
и **Rust**. Скрипт лежит в детали и оживляет её: монетка исчезает, лава убивает, дверь открывается по [E], платформа ездит.

## Что такое WebAssembly — простыми словами

C++ и Rust браузер сам не понимает. Их сначала **собирают** (компилируют) в файл `.wasm` — это «WebAssembly»,
быстрый код, который браузер умеет запускать. Файл работает в «песочнице»: ни сайта, ни аккаунта, ни интернета
он не видит, а с миром общается только через функции SDK (это и есть файлы в этой папке).

| Язык | Где собирается | Что нажать в студии |
|---|---|---|
| C++ | прямо на сайте | «⚙️ Собрать», потом «▶ Играть» |
| Rust | прямо на сайте (Chrome / Edge / Яндекс на компьютере) или у себя | «⚙️ Собрать» (или «📦 Загрузить .wasm»), потом «▶ Играть» |

## C++ — прямо на сайте

1. В студии создай скрипт внутри детали (📜 Скрипт), в редакторе кода выбери язык **⚙️ C++ (WebAssembly)**.
2. Нажми «📚 Примеры» и выбери готовый (монетка, лава, дверь…) — или «🤖 Задание для ИИ»: опиши, что нужно,
   вставь задание в DeepSeek / GigaChat / Алису / ChatGPT, а ответ — в поле кода.
3. Нажми **«⚙️ Собрать»**. В первый раз сайт скачает компилятор (около 23 МБ — один раз, потом он берётся из кэша
   браузера), сборка занимает несколько секунд.
4. Ошибки появятся во «Выводе» по-русски с номером строки, например
   `Строка 4: ошибка: неизвестное имя «coins» (опечатка или не объявлено)`. Исправь и собери ещё раз.
5. «✅ Собрано» — жми «▶ Играть».

Главное правило: в скрипте должна быть функция `void start() { … }` — она запускается один раз при «▶ Играть».
Остальное делают обработчики событий. Пример (монетка):

```cpp
using namespace d37;

void start() {
  Part coin = script_parent();          // деталь, в которой лежит скрипт
  coin.on_touched([coin](Player p) {    // кто-то коснулся
    if (!p) return;                     // не игрок — ничего
    p.add_stat("Монеты", 1);
    sound("coin");
    coin.destroy();
  });
}
```

Можно `std::string`, `std::vector`, `printf` (пишет во «Вывод»). Нельзя: интернет, файлы, `sleep` и долгие циклы —
вместо них `delay`, `every`, `on_update`.

## Rust — прямо на сайте

1. В студии создай скрипт внутри детали (📜 Скрипт), в редакторе кода выбери язык **🦀 Rust (WebAssembly)**.
2. Нажми «📚 Примеры» или «🤖 Задание для ИИ» — как у C++. Главное — функция `fn start() { … }`; SDK (`d37.rs`)
   сайт подключает сам, строки `#[macro_use] mod d37; use d37::*;` можно не писать.
3. Нажми **«⚙️ Собрать»**. В первый раз сайт скачает настоящий компилятор Rust (rustc с LLVM, собранный в WebAssembly)
   и стандартную библиотеку — около 38 МБ один раз, потом из кэша браузера. Сборка — 1–3 секунды.
4. Ошибки — во «Выводе» по-русски с номером строки и подсказкой, например
   `Строка 5: ошибка E0599: у struct Part нет метода «set_colour» … подсказка: есть похожий метод «set_color»`.
5. «✅ Собрано» — жми «▶ Играть».

Сборка Rust на сайте работает в **Chrome, Edge или Яндекс Браузере версии 137 и новее на компьютере** (ей нужна
общая память для потоков компилятора — её даёт заголовок Document-Isolation-Policy, а его понимают только эти
браузеры). В Firefox, Safari и на телефоне — собери у себя (ниже) и загрузи файл.

## Rust — у себя на компьютере

Один раз — установить Rust (бесплатно, официальный установщик):

1. Скачай `rustup-init.exe` с https://rustup.rs и запусти в «Командной строке» так (не понадобится Visual Studio):
   ```
   rustup-init.exe -y --profile minimal --default-host x86_64-pc-windows-gnu
   ```
2. Закрой и снова открой «Командную строку», добавь сборку для WebAssembly:
   ```
   rustup target add wasm32-unknown-unknown
   ```

Каждый скрипт:

1. Возьми шаблон — папку `sdk/rust-template` (три файла: `Cargo.toml`, `src/lib.rs`, `src/d37.rs`; с сайта их можно
   скачать по адресам `https://dan4ik37.vercel.app/sdk/rust-template/Cargo.toml`, `…/src/lib.rs`, `…/src/d37.rs`).
2. Напиши код в `src/lib.rs` (или вставь пример из `sdk/examples/*.rs`, или ответ ИИ — «🤖 Задание для ИИ» в студии
   с языком Rust). Файл `src/d37.rs` не меняй — это SDK сайта.
3. В папке шаблона выполни:
   ```
   cargo build --release --target wasm32-unknown-unknown
   ```
4. Готовый файл: `target\wasm32-unknown-unknown\release\d37_script.wasm`.
5. В студии: скрипт → язык **🦀 Rust (WebAssembly)** → «📦 Загрузить .wasm» → выбери файл. Исходник (lib.rs) можно
   вставить в поле кода — для себя и для ИИ. «▶ Играть».

Паника в Rust (например, выход за границы массива) — красная строка во «Выводе» с номером строки `lib.rs`.

## Примеры

`examples/` — одни и те же скрипты на двух языках: `coin` (монетка), `lava` (лава), `door` (дверь по [E]),
`spinner` (крутилка каждый кадр). Ещё больше — в студии, «📚 Примеры».

## Шпаргалка: C++ и Rust

| Что | C++ | Rust |
|---|---|---|
| деталь со скриптом | `script_parent()` | `script_parent()` |
| найти по имени | `find("Выход")` → `Part` (проверка `if (p)`) | `find("Выход")` → `Option<Part>` |
| положение | `p.position()`, `p.set_position(x, y, z)` | `p.position()`, `p.set_position(vec3(x, y, z))` |
| размер, поворот (°) | `size()/set_size`, `rotation()/set_rotation` | так же |
| цвет | `set_color(1, 0, 0)` или `set_color(0xff0000)` | `set_color(1, 0, 0)`, `set_color_hex(0xff0000)` |
| прозрачность, столкновения, закреплена | `set_transparency`, `set_can_collide`, `set_anchored` | так же |
| материал, форма | `set_material("neon")`, `set_shape("ball")` | так же |
| копия, удалить, новая | `clone()`, `destroy()`, `new_part()` | `clone()`, `destroy()`, `new_part(None)` |
| касание | `p.on_touched([](Player pl) { … })` | `p.on_touched(move \|pl\| { … })` (`Option<Player>`) |
| подсказка [E] | `p.prompt("Открыть", [](Player pl) { … })` | `p.prompt("Открыть", move \|pl\| { … })` |
| каждый кадр | `on_update([](double dt) { … })` | `on_update(move \|dt\| { … })` |
| через N секунд / каждые N | `delay(2, [] { … })`, `every(1, [] { … })` | `delay(2, \|\| …)`, `every(1, \|\| …)` |
| плавно | `p.tween_position(to, TweenInfo(1).ease(Ease::Sine))` | `p.tween_position(to, TweenInfo::new(1).ease(Ease::Sine))` |
| игрок | `pl.add_stat("Монеты", 1)`, `set_health(0)`, `teleport(…)`, `message("…", 3)` | так же |
| вывод | `print("…")`, `printf(…)`, `print(Text() << "Счёт: " << n)` | `print("…")`, `log!("Счёт: {}", n)` |
| экран и звук | `gui_message("…", 3)`, `gui_text("ключ", "…")`, `sound("coin")` | так же |
| случайность, время | `random_float()`, `random_int(1, 6)`, `game_time()` | так же |

## Ограничения (защита сайта)

- Скрипт работает в песочнице без сети; завис дольше 3 секунд — скрипты останавливаются.
- За один вызов скрипта — не больше 200 000 обращений к сайту и 5000 изменений мира; памяти — до 256 МБ;
  после 30 ошибок скрипт останавливается. Файл `.wasm` — до 2 МБ.
- Неверный адрес строки, неверный номер детали, падение (trap) — это ошибка во «Выводе», а не поломка сайта.

## Для программистов

- Всё про ABI (модуль импорта `d37`, номера свойств, экспорты `d37_start` / `d37_event` / `d37_update`) — в шапке `d37.h`.
- C без libc: `clang --target=wasm32 -O2 -nostdlib -Wl,--no-entry -include d37.h script.c -o script.wasm`
  (обработчики — функции через `D37_CB(f)` / `D37_CB0(f)`, строки — `d37_printz`, числа — `d37_fmt`).
- Сайт собирает C++ так: `clang++ --target=wasm32-wasip1 -mexec-model=reactor -std=c++20 -O2 -fno-exceptions -Wall
  -include d37.h script.cpp` (флаги — `CPP_ARGS` в `js/engine/lang-wasm.js`). У себя то же даёт wasi-sdk.
- Проверка без браузера: `node scripts/lang-wasm-test.cjs` (ручной модуль + настоящие clang и cargo, если установлены).

Компилятор на сайте — [YoWASP Clang](https://yowasp.org/) (npm `@yowasp/clang`, лицензия ISC; сам LLVM — Apache-2.0
с исключением LLVM), загружается с cdn.jsdelivr.net.
